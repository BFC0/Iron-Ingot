## 实验和门槛

- B0：复现原冻结效率记录，误差≤1e-12；不作为新实际预测成绩。
- B1：旧效率/费用特征在合格样本上的折内重拟合；市场等权。
- B2：训练市场校准资源强度，结合环境总量、显示区间与JSON人数更新历史训练观测；验证标签不变，水通道不参与状态校准。
- B3：实际招聘/裁员直接监督费用，与相同样本的旧人数路径比较；已公布补偿比例固定，结果仅作条件规则核验。
- C：检验人均工资是否只是工资/人数的派生值；相容则不新增自由参数。
- B4：在B2校准基础上，用内层折外残差探索上期人员流动对下一期效率的修正。正式1→2单一转移只有条件研究资格，尚无时间外部署资格。
- E/F：检验产量/路线数量×结果页单位强度能否解释环境总量；同期期末强度不作为事前已知参数，保留条件公式。

每个可比阶段/回合/国家/产品至少5个合格市场。外层留整市场，标准化、系数校准、残差构造及正则选择均在训练内。正则网格沿用项目规范，误差相差≤1%优先简单模型。市场配对重采样1000次，种子20261013。

研究重拟合门槛：主MAE改善>1%，至少三分之二市场改善，增量95%重采样区间下界>0，相关下游工资不得恶化>1%，且没有校准冲突折。所有范围仅为历史条件研究，部署还需独立后续回合验证、曲线历史绑定和预测时点核验。指标分母为零时改善率不可算。
