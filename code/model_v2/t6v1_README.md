# t6v1 回合6终局条件应用

基于冻结t6v0的正式5国别需求、材料、风险及历史效率锚点；独立拟合已归档的正式6三条投入曲线，不新增经营训练标签。菲律宾迁移印尼国别模型，以1600／23美元为十队共同价格锚点，总量5／105千单位。泰国机器当期生效；印尼本期产量固定0，新增投资计本期现金及0%／15%折旧情景。只计算正式6，不产生第7回合经营或残值收益。

构建与两候选求解：

```powershell
& '<LOCAL_USER_DIR>\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' work/build_t6v1.py --out output/t6v1/<运行目录>
```

运行目录须先创建`work_log.md`记录授权及进行中状态。每次使用新目录；默认每目标两个随机种子、各最多300轮差分进化，随后按显示精度和全部机器／贷款档位坐标检查。搜索未收敛会保留原始状态，不宣称全局最优。

保存的应用包支持离线复算：

```powershell
& '<LOCAL_USER_DIR>\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' code/model_v2/t6v1.py --bundle output/t6v1/<运行目录> --request output/t6v1/<运行目录>/example_request.json
```

请求严格包含`version: "t6v1"`、`round: 6`、`decision_vector`及`scenario`。28维向量及边界以包中`variable_names`、`bounds`为准：6价格、6一般营销、6设计师营销、2研发、1运营、2泰国机器档、2印尼机器档、2产能分配、1贷款档。机器梁每档1千单位、连接件每档20千单位，贷款每档100千美元。物流每产品枚举6种顺序，输出固定顺序跨情景回放。

56项字段按实际子页归档次序输出。39项经营字段中，28项数值参与条件搜索、6项物流枚举、4项投标及1项分包未求解；17项预估／派生字段随候选重算或标为终局停用。营销合计使用t6v0公司费用代理，细分分配效果不可识别；报告不将任意分配称为细分最优。

财务采用正式5期末结转假设，保留15项独立期初核验缺口；税亏、折旧、厂房支出及收付计息时点分别列假设和压力情景。自动短贷为期末情景复现，全期现金时序未核。投标及分包保持明确未求解占位，不把机会当确认销量。没有平台填写或提交。

内部核验覆盖需求份额、旧国别冻结特征独立回放、菲律宾关闭、36对物流顺序、产量库存及会计守恒、机器生效、印尼财务影响、终局期限及非法请求。它们是实现检查，不是独立前向精度验收。
