# t4v1杠杆幂函数利率模型误差原因

分析日期：2026-10-14，北京时间。对象：t4v1正式3完整数据训练版本 `20261014T153914569881+0800`。仅读取归档，未修改权威模型或平台决策。不要输出真名，姓名统一用首字母替代；本文仅用市场及归档列编号。

**主要原因是：权益接近零使杠杆比率暴涨，而无上限幂函数把普通杠杆区间拟合出的曲线外推到1733.79倍；整市场留出恰好把唯一极端样本全部移出训练集。** 巨大误差不是普遍发生在93个样本上，也不是优化未收敛造成。

长期利率模型为 `r = 0.04 + a × x^b`，其中 `x=(长期贷款+短期贷款)/股东权益`。r、a使用小数；显示百分数需乘100。1基点=0.01个百分点。

## 误差集中在哪里

93个有效正权益样本中，92个杠杆在0～1.281955倍，另1个为1733.785714倍，中间没有训练样本。

| 指标 | 杠杆幂函数 | 权益比指数函数 |
|---|---:|---:|
| 全样本训练MAE，基点 | 3.0050 | 1.1869 |
| 原报告整市场留出MAE，基点（10折等权） | 8,782,495.9385 | 32.1094 |
| 留出市场5的MAE，基点 | 87,824,931.6512 | 310.1731 |
| 其余9折合并83条验证记录MAE，基点 | 3.0896 | 1.2160 |

市场5第1列的期末权益为14千美元，长期贷款18,100千美元、短期贷款6,173千美元，合计有息债务24,273千美元。因此 `x=24273/14=1733.785714`。实际长期利率14.26%，风险溢价10.26个百分点。

留出市场5后，模型仅用83条记录训练，最大杠杆1.281955倍，拟合参数 `a=0.00216316427, b=2.34903970`。对该极端状态的预测为：

`100 × (0.04 + 0.00216316427 × 1733.785714^2.34903970) = 8,782,507.3815%`

单条误差达到878,249,312.1505基点，占全部93条留出记录绝对误差之和的 **99.9999703%**。原报告按10个市场MAE等权平均，因此还会再经过市场5的10条记录和10个市场两层平均。直接合并93条记录的MAE为9,443,543.7951基点；两种聚合口径略有差别，都揭示同一极端外推失效。

只从已计算的验证记录中排除这一条，剩余92条MAE为2.8347基点。这只用于分解错误贡献，**不能据此删除真实样本或宣称模型验证通过**；其中多折训练仍包含极端样本。

## 为什么会这样

1. **权益作为分母，在接近零时产生奇异性。** 本例权益/资产仅0.056959%，普通债务规模被换算为1733.79倍杠杆。只要b>0，`a×x^b`就会随权益趋近零无限增大。正式3实际样本只显示14.26%的有限利率，未支持如此急剧的外推；但单个极端样本也不足以证明平台存在某个固定利率上限。

2. **样本分布存在巨大空档，整市场留出暴露了它。** 极端样本只出现在市场5；留出它后，测试杠杆是训练最大值的约1352倍。其他9折的训练都包含这条极端记录，因而不会出现同样爆炸。市场5其余9条的幂函数绝对误差均值仅约0.48基点，整折误差几乎被第1列独占。验证设计揭示了模型的适用范围问题，不应通过把该样本放回训练集来掩盖。

3. **单一幂函数无法兼顾普通区间与极端区间。** 全93条拟合时，指数被拉低到 `b=0.612644`、系数变为 `a=0.001063765`；仅对92条普通区间样本做诊断拟合，得到 `b=2.353372`、`a=0.002165990`。普通样本训练MAE由全样本参数下的3.0364基点降到0.4743基点。这表明同一条幂曲线为兼顾唯一极端点，明显牺牲了普通区间拟合。最小二乘按残差平方计损失，极端标签更容易影响参数。上述删除样本拟合只是影响度检查，不是新模型验收。

4. **验证直接计算外推，没有检查每折训练范围。** `t4v1.py`的利率留出循环直接调用 `interest.premium()`；这一函数仅计算幂或指数。独立预测接口 `interest.predict()`虽有范围检查，但没有在该循环中使用。最终注册表的全样本最小/最大范围又被唯一极端点撑开到0～1733.79倍，单看这个范围不能发现中间的巨大无数据区间。参数边界 `a≤10、b≤30` 也不能约束预测利率上限。

## 已排除的主要疑点与次要问题

对全样本和留出市场5两种数据，各使用4组初值复拟合，再固定b解析求最优a，对b作网格及一维优化。得到的参数和损失接近原结果，原结果也逐折复现。因此，没有证据把巨大误差归因于初值不佳、局部极小值或迭代次数不足。

权益显示精度为14±0.5千美元。固定债务作敏感性计算，杠杆仍在1674～1798倍，留出预测仍约809万%～957万%。舍入会放大不确定性，但解释不了与实际14.26%的巨大差距。本分析核对了93条财务特征和利率标签的计算关系，并核验其归档源文件SHA256；这确认归档及计算一致，不等于独立证明平台原始数值完全无误。

基准利率5%的文字叙述与4%的参数表冲突仍需保留。不过93条中92条实际利率低于5%，7条零有息债务样本的利率恰为4%。在当前非负风险溢价假设下，4%与这些结果更一致；把基准改成5%会产生大量负标签，不能修复幂函数的巨大外推误差。

另外7家公司因负权益被排除，说明当前模型并未覆盖破产或负权益状态。幂函数使用有息债务/权益，指数函数使用权益/总资产，两者也不能直接互换：资产负债中还有应付账款及其他负债。其对普通区间剩余误差的具体影响，以及期初、期末或平均状态哪个对应计息机制，本次没有识别。

## 对模型使用与后续修复的判断

当前应继续保留未部署状态。若后续修复，首先应在每折验证及预测时识别超出训练支持的状态，并同时报告范围内误差、范围外样本数和全部误差，不能只隐藏极端误差。权益接近零及负权益应作为需要独立规则核验的状态；普通区间幂函数不宜直接延伸过去。

后续可检验有界、饱和或分段函数，但上限和分段规则需要平台证据及额外高风险样本。换成当前权益比指数函数只能减轻爆炸，留出市场5仍预测45.2357%，比实际高30.9757个百分点，尚未解决尾部泛化。普通区间误差较小也只属于给定实际期末状态的同期条件验证，不能当作未来回合利率预测成绩。
