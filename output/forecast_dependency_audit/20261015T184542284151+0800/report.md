# 预计／预测字段与训练依赖检查

检查时间：2026-10-15（北京时间）。范围：t4v1正式3训练数据、t5v0正式4训练数据、t5v1正式4营销训练及正式5冻结应用；复用已有原件，没有操作平台。

**结论：在以上范围内，未发现把个人决策生成的“预计／预测／预估”页面值当作固定外生已知量进入实际训练。** 这些值是给定当时决策的条件反馈，改变决策后必须重算；被采集、数值已知不代表对其他决策仍然有效。当前代码区分实际训练、预算复现及前向情景，但这一结论不扩展到所有历史脚本或平台真实机制。

## 字段分类与实际使用

| 字段／页面 | 应有性质 | 本次检查结果 |
| --- | --- | --- |
| 销售页“预计销售额, 千单位”及今年收入、成本、毛利、EBITDA | 当前草稿下预算输出，依赖需求预估、供给、价格及费用 | 营销训练读取结算后的marketdetails和incomestatement；没有使用这些销售预算表格作为实际标签 |
| 投资页“需求预测, 千单位”的今年／下回合值 | 手填需求和增长率的条件计算 | 未作为训练的真实需求、行业总量或独立预测精度依据 |
| 个人需求、市场增长、下回合增长、效率、长贷利率13项预估 | 玩家输入，不是真实终值 | 正式4最终列表42项分为29项决策和13项预估；训练读取守卫逐项拒绝13项预估 |
| 生产页单位可变成本、生产、人数、工资等 | 草稿决策和预估驱动的预算计算，即使没有“预计”字样也不应视为固定参数 | 材料、工资和效率基点读取结算实际产量、人数、产能、成本；前向路径重新计算生产和工资，没有固定使用当前页生产人数 |
| 当前机器产能41.67／412.25千单位 | 零本人新增投资条件下的容量基准 | 应用模型在该基准上加候选投资；改变投资后容量会变。不能把页面“今年产能”在任意投资下固定不动 |
| 销售图“较于其他竞争对手”的位置y | 随当前决策变化的相对位置反馈 | 保存作诊断，不作为固定需求乘数；应用采用重要性x的回合比值，映射仍是分析假设 |
| 研发／运营图的“曲线”与“回合效果” | 函数曲线与当前输入对应的效果须区分 | 拟合选择“曲线”系列；应用按候选横轴重新求值。当前支出到有效横轴的映射仍未由真实经营验证 |
| 前景“泰国预计增长7%／印尼萎缩5%”、原材料跌幅等文字 | 公布的宏观前景及情景信息，不由个人决策生成 | 可作为外部情景来源，但不是必然实现的产品需求。正式5应用采用1.07／0.95并做压力情景，不能称确定真实增长 |

## 来源核验

- 对两个保存的训练数据集递归追踪并去重，检查6420个来源单元格：6190个实际结果、200个未带category的历史结果引用、正式3和正式4最终决策引用各15个。核对来源哈希、行列和数值，来源行标签未出现“预计／预测／预估”，来源文件未使用budget页。200个旧引用另限于历史市场详情、损益、生产详情来源，未因缺category直接放行。
- 正式4营销376组配对的期末5项价格、需求、一般营销、设计师营销、研发，全部从结算原件重建一致；264组满足原有拟合资格。这是重建数据核验，没有重新训练系数。
- 正式4训练的13项玩家预估全部经真实final_field读取函数拒绝；已有决策、财务及数量自检通过。
- t5v0因缺其他99队真实最终决策暂停竞争需求重训；t5v1营销另用明确标识的公司实际合计费用代理。代理的因果识别和国别分配问题仍在，与本次“是否混入预算预测”是两项问题。

## 改值测试

从t5v1保存的第一套方案、第一种情景出发，只改内存副本，不覆盖模型或历史结果。

| 测试 | 结果 |
| --- | --- |
| 将current中的13项玩家预估全部改为原值×1.7＋0.123，保持经营决策不变 | 默认前向路径完整输出完全一致；说明没有偷用这些当前手填预估作为固定真实量 |
| 同样改值，调用budget=True | 预算复现输出发生变化；这是复现当前草稿预算所需的显式条件路径，不是实际训练或默认前向调用 |
| 泰国复合梁价格降低10% | 对应需求3.7878→5.180160千单位 |
| 一项一般营销降低10% | 需求重新计算；合计代理映射下会影响多个产品／国家，不代表已识别细分因果 |
| 复合梁研发降低10% | 两国复合梁需求均重新计算 |
| 运营降低10% | 复合梁效率0.170078→0.166781；连接件17.003984→16.674413千单位／人 |
| 复合梁机器投资增加1档 | 当期容量41.67→42.67千单位 |
| 长贷变化增加1档（100千美元） | 长贷利率5.030875%→5.031374%；仍是现有条件风险模型的计算，不代表平台时点机制已验证 |

“会重算”只证明依赖存在，不证明该响应函数、跨期财务或宏观假设正确。尤其风险训练给定实际期末状态，应用使用推算状态；不能把条件回溯误差当成事前经营精度。
