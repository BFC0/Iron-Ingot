# t2v0-um：正式2专用入口

保留 unified-market 的需求、效率、风险及材料函数结构；仅练习2实际标签训练，正式1期末作为正式2期初状态。同回合各市场共享是用户假设，两国分别训练，份额在各市场各国家的10队内部归一化。下游函数结构不随上游曲线改变；输入必须由绑定的第2回合曲线生成。

2026-10-12更正：研发/运营曲线还依赖上一期实际投入；同回合共享须匹配历史条件或验证历史映射。销售四项乘数分别是当前相应输入的函数值，不能当固定系数。现有固定ρ和单条曲线训练结构仍为历史近似，尚未支持不同上期状态的完整响应族；本次只更正证据入口与说明，未重训或启用正式2预测。

不要输出真名，姓名统一用首字母替代。输出使用市场/队伍编号。旧源、旧模型、旧代码及 latest 均不覆盖。

## 运行

```powershell
python code/t2v0_um/self_check.py
python code/t2v0_um/run.py
python code/t2v0_um/run.py --evidence <已核验的证据清单.json>
python code/t2v0_um/run.py --train-practice2-components
```

每次排他创建 `output/t2v0-um/<北京时间运行编号>/`。默认生成实际数据、正式2期初状态、48项对照、证据模板及检查。已补查正式2前景归档，33项前景内容及给定值与练习2一致；其余15项仍待完整配对。没有绕过正式2迁移门槛的选项。任何差异或缺项都关闭迁移。

用户2026-10-12新增授权：使用练习2训练实际利率和材料单位费用，并调整受影响参数。`--train-practice2-components`只开放练习2内部组件训练，不开放正式2预测。输出 `components.json`、`component_dataset.json`、`component_validation.json`、`component_checks.json`及 `parameter_changes.json`；整体状态为 `PRACTICE2_COMPONENTS_TRAINED_MIGRATION_BLOCKED`。所有标签都是练习2的100家公司实际，练习1只提供历史；不会调用两个原模型混合期训练入口。

实际利率复用新模型的两种风险函数及嵌套整市场选择；材料保留新模型的比例结构、总费残差拟合及显示兼容区间。练习2只有1053这一种公布材料价，无法独立区分跨回合比例调整与固定单位差额，不能据此重新选跨回合函数形式。两个旧模型参数仅作前后对照，不参加本次拟合。

`calibrated.conditional_accounts(components, state, decision, demand, efficiency, assumptions, phase=..., round_number=2)`保留原财务账户公式，绑定练习2给定参数和新材料费用；迭代期末财务状态→风险利率→利息→利润/现金/权益/资产，收敛后核验余额。旧材料残差不再叠加。必须显式提供厂房投资、厂房折旧、应收/应付天数以及税亏状态，不加载旧经验默认值；有期初库存、短贷、大客户或新增短贷需求时拒绝，计息时点仍是旧方程中的条件假设。默认关闭的正式2门槛同样适用于此接口。输入需求和效率是调用者明确提供的情景，本接口不表示缺曲线的需求/效率已重训。

现有正式2生产图表只有 round=2，缺完整阶段身份及练习2配对曲线；只能列为候选资料。练习2销售截图和正式1销售散点不能替代正式2销售资料。已存在的正式2前景位于 `output/formal_update/20261011T223000+0800_sources/formal2_outlook.json`，前次遗漏已更正，不再把该前景列为缺失。

## 证据清单

由最新运行的 `evidence_template.json` 补齐，两期各自包含 `identity` 和 `items`。模板中的练习前景是旧源的待核验候选；旧源身份不完整时须新增带身份的归档，不能改旧源元数据。`required_items` 列出5段前景、28项参数、2条曲线、两国各4项销售乘数及5类补充给定参数清单。

- 身份及每项源文件必须保存 `phase`（practice/formal）、`round=2`、`market_id=5`、`selection_verified=true`、`captured_at`；先用网页当前状态、回合选择及个人区域只读核验，不能凭文件名补身份。跨市场共享按用户假设，不伪装为10市场已独立核验。
- 引用格式：`{"file":"项目内原始归档.json","sha256":"原件哈希","pointer":"/JSON/字段"}`。表格文本可用 `line`、`column` 引用源快照表格，省略 pointer。每项包含 `value`、`unit`、`phase`、`round`、`reference`；value必须等于原件引用的值。统一单位、字段和结构后保留原件链接；无法溯源的手填值不能作为证据。
- 曲线 value 为 `{"form":"power或saturation","x":[原始横轴点],"y":[原始纵轴点],"conditions":{"previous_investment":上一期对应实际投入千美元}}`；研发 power、运营 saturation。两期比较必须保持相同历史条件及横轴含义，JSON/SVG配对去重。不同历史投入下曲线不同不能单独否定前景或隐藏机制相同，需另行核验历史映射；当前门槛保守拒绝这种未适配迁移，不宣称机制不同。
- 销售项是各类别自己的输入—乘数配对，必须保持国别和类别对应。value采用 `{"kind":"curve","factor":"price/general/designer/rd之一","x":[该类别当前决策输入],"y":[对应显示乘数],"input_unit":"原始输入单位","conditions":{"其他输入":"固定值及历史状态"}}`。同屏四个类别各提供一个函数显示点，不是同一函数的四个样本。分别积累同条件下多个取值后拟合；不接受 published_coefficient，也不使用图中横向权重替代当前输入。补充给定参数只含公布常量/规则，不含决策、预测、预算和结转状态。production、investments、logistics、orders、finance各列完整字段、值和单位（`字段:{"value":值,"unit":"单位"}`），记录 `coverage="ALL_VISIBLE_GIVEN_PARAMETERS_REVIEWED"`。没有额外参数的页面明确记录 `{"no_additional_given_parameters":true,"reviewed_page":"页面来源"}`，不能用空值表示已检查；自动核验不能发现人工遗漏的字段。
- 原始数值精确比较。只有数值项明确声明源显示 `resolution` 才按两边取整区间比较；字符串、数组及结构逐项精确比较。不自行宽放容差。

全部可见项一致才拟合练习2曲线、重训两国需求、运营效率/延续、两风险函数及材料残差。行业总量外生、研发延续0.5、营销尺度1000、公司合计营销代理保留原定义和限制。风险用练习2基准利率扣除，各队实际利率单独读取；材料残差扣除练习2公布原料成本，避免旧版硬编码3%与900。给定参数保存于一致性证据，不载入旧版固定财务参数；完整财务分支仍未实现。

## 预测与验证

`bound_prediction(rows, model, curve, phase)` 拒绝错误国家、阶段、回合、情境、曲线及不完整竞争组。新版本仅支持 practice/2 条件验证和 formal/2 候选预测。

`freeze_forecast(rows, model_path, totals)` 验证启用模型哈希，读取正式1实际状态，核对正式2历史投入；输入须为无实际需求标签的完整竞争决策情景，行业总量通过 `(market_id, country)` 明确提供。调用前应核验正式2结果尚未公布；接口不联网，无法自动确认发布时间。每次在新的时间戳目录冻结模型哈希、输入和需求预测，原训练目录不变。当前没有提供决策/对手/行业总量情景，未冻结正式2预测。正式2公布后先评分冻结版本，重训另建版本。

需求外层每次留2整市场，内层仅其余市场选参、估计尺度；实际总量和对手决策用于条件回算，不是事前需求成绩。税损、存量、订单条款、短贷等缺口保留；本版本不拓展完整财务、平台操作或第3回合情境适配。
