# 新旧数据差异与新增模型探索

北京时间：2026-10-13。用户要求比较新结果页与旧数据集，探索新增数据类型支持的新模型。本次没有训练，也没有操作平台。姓名不输出，团队仅按列位置识别。

## 比较基线与方法

旧基线分两层：①`结构化模型输入.json`、`历史市场建模样本.csv`、`output/formal_update/20261011T225637591747+0800_training/dataset.json`代表已有提取与训练字段；②37个已独立核验身份的旧市场/历史回合打印原件，代表以前已经拥有但可能未入模的数据。

新基线固定为`output/round_close/20261012T221044.031+0800/audit/20261013T120552.995614+0800`快照：390/750页，407份来源、8772表格行、669条图表初始化记录。别的任务继续补采不改变本次比较基线。页数、行数和图表数不等于独立训练样本数。

比较了旧训练字段并对新结果页数值行按栏目、表、行和标题保留上下文，生成300组字段/分区对比。空格、问号和中英文标点做保守归一化；不删除单位，不仅凭标签字符串判定语义新增。环境页各行经常都叫“复合梁”、物流页都叫“运往印尼”，必须看上方计量标题和单位才能识别新数据类型。

可复核产物：[逐字段对比](字段逐项对比.csv)、[统计与来源哈希](对比核验.json)、[派生性诊断](诊断补充.json)、[可复现脚本](compare.py)。脚本使用既有只读表格解析器，有归一化、NaN/数字解析和目标字段存在性断言；原件不改写。

## 一、真正新增的数据类型

| 新类型 | 新结果页内容 | 旧资料情况 | 新增能力 |
| --- | --- | --- | --- |
| 生产环境资源 | 二氧化碳排放总量/单位强度、能耗MWh/kWh、用水m³/升 | 37份旧配对打印原件未出现这些环境标题或CO2；旧训练字段也无 | 新增资源预测目标、物理一致性约束及历史产量精度校验渠道 |
| 运输排放 | 分目的地CO2总量kg、单位销售排放g、综合单位销售排放 | 旧物流数量已存在，排放口径未出现 | 新增运输排放预测与路线结构核验；未证明排放影响需求 |
| 人员流动 | 上回合人数、辞职、招聘+/裁员−、本回合人数、裁员比例 | 旧原件有“生产线人工数量”，故本回合人数不是全新状态；但没有这些显式人员流动字段 | 区分离职、主动调整和人员净变动，提供调整事件及成本的直接监督 |
| 人均工资 | 每人平均工资 | 旧原件有工资总额、工资分摊及人数，可以派生近似人均值，但没有该直接字段 | 直接校准有效工资与班次关系，减少人数和总工资共同反算的误差 |
| 更精确的历史观测 | 员工人数时间序列的JSON原始浮点值；图表原始JSON | 对比旧参考原件图表初始化记录缺失；原表人数/效率有显示舍入 | 改善历史效率、用工参数估计及误差区间，不当作额外独立样本 |

这里“未出现”指已配对的37份旧打印原件和指定旧数据集，不声称以前所有截图或每个未配对来源都没有。

## 二、不能算真正新增的内容

| 字段或分区 | 比较发现 | 对模型的处理 |
| --- | --- | --- |
| 已收预付款、额外实收资本、直接税 | 旧打印原件已有；新标签多一个问号/空白 | 不以新数据名义重建风险、税或订单模型 |
| 累计收益、销货成本、本回合/下一回合复合梁 | 旧标签已有对应项，单位或空格写法不同 | 保留时点和单位，做语义配对 |
| 总流动资产、总需求、总份额、销售额合计 | 多为已有项合计或改名；不能仅由新标签认定新变量 | 可做加总核验；确认各自数量/金额/份额口径 |
| 社会价值创造：人员、股东、债权方、政府、供应商 | 旧原件均已有；典型情况下为工资、利润、利息、税费及采购的再表达 | 不是新增独立特征；当期值预测当期利润会有信息泄漏 |
| 股息支付、股票发行/回购现金 | 旧配对标签未出现；本快照仅20个数值单元格，全部为0 | 无法识别作用系数，且股权操作在当前范围外 |
| 产品机器产能 | 旧有总体生产能力，新增明确产品机器口径 | 有助区分资源约束；属于状态/规则核验，不能直接当需求驱动 |

预付款在本快照260个单元格中有10个非零，但原件早已拥有该类型。它能补充订单状态研究，不能作为“新结果页才出现”的证据。

## 三、新变量有没有独立信息：已做的诊断

- 环境生产数据共26个市场/阶段/回合结果组、每组10队，即每项260个数值单元格；这些不是260条独立时间路径。
- 单位生产CO2为1355.31–1355.32 kg/单位；能源为4778.38 kWh/单位；水为10307.14升/单位。没有超过显示容差的队间变化，单位能耗与单位用水在检查范围内完全相同。
- 总排放、总能耗和总用水随产量变化。用1355.315 kg/单位作诊断系数反算产量，与显示产量的最大差0.004972千单位，落在产量两位小数显示的约半个末位内。这不是训练参数或已证明的精确官方系数。
- 人员流动各字段均有260个数值单元格；招聘/裁员非零259个、裁员比例非零63个。平均工资为28–48.63千美元/人，在20/26个结果组中有明显队间差异。
- 人数等式`上期人数+辞职+招聘/裁员=本期人数`最大显示残差0.1人；`辞职≈−0.1×上期人数`最大残差0.05人。直接算离职率会出现7.69%–12.5%，主要可由人数显示舍入解释，不能据此声称离职概率存在真实随机波动。

因此新增数据目前提供的主要价值是人员事件的监督与精度改善。环境总量不能作为三种独立经营驱动反复加入同一回归；尚无证据支持“减排带来更高需求”的参数。

## 四、值得探索的新模型及详细参数

### A. 多观测约束下的历史状态校准模型：优先

这是旧输入整理流程没有的模型层：结合显示产量、生产环境总量、单位强度、全精度人数及效率，联合估计更精细的历史生产状态，再训练需求/效率/成本模型。

候选观测关系：`CO2_t≈k_C q*_t`、`energy_t≈k_E q*_t`、`water_t≈k_W q*_t`、`q*_t≈N*_t η*_t`，所有单位转换明确保存。生产排放用公吨、产量用千单位时，k_C数值等于kg/单位；能源MWh与千单位对应kWh/单位；水m³与千单位对应升/单位。

| 参数/状态 | 含义和作用 | 类别与识别 |
| --- | --- | --- |
| k_C,k_E,k_W | 每单位产出的碳、能耗、水系数 | 按产品/技术条件固定或低参数校准；新产品不能继承 |
| q*,N*,η* | 潜在真实产量、员工数、生产效率 | 历史状态，不是需求作用系数；通过观测区间和恒等式联合约束 |
| σ_q,σ_N,σ_η等 | 各来源显示精度/观测误差 | 优先取已知精度；作为拟合权重配置，不是经营作用参数 |
| 产品/技术/回合键 | 选择物理系数及观测来源 | 分类条件，不连续回归 |

训练方法：先用显示取整区间做约束最小二乘/可行区间校准，不必立即上复杂概率框架。三个环境通道可能来自同一内部产量，不能当独立噪声观测乘增置信度；人数图表与表格同一原点也不能重复计样本。

优化目标：减少历史效率只显示0.17等粗精度引入的参数偏差。用未参与校准的渠道/完整结果组检验，再比较下游整市场、跨回合留出误差。部署预测仍从当期已知状态和决策出发，不能使用尚未结算的当期实际排放反算当期产量作为预测特征。

### B. 人员调整事件—调整成本模型：优先

新增的辞职与招聘/裁员字段，使模型可以直接区分“自然离职”和“主动裁员”，不再只从前后人数差猜测。

候选：`N_avail=N_prev−quits_abs`；`H=N_required−N_avail`；`F=w_base κ_F max(−H,0)`。先核规则与连续人数/取整，再对不能解释的费用做分段校准。

| 参数 | 含义和作用 | 处理 |
| --- | --- | --- |
| δ_N | 自然离职比例 | 当前先验证给定10%基线；没有证据就不训练随机离职模型 |
| κ_F | 每裁员一人需要几倍基准工资的补偿 | 用真实裁员量及实际解聘成本校准；当期规则若给定则固定 |
| κ_H | 每招聘一人额外费用 | 只有规则或独立费用标签支持时加入；不能凭新增招聘数量造招聘费用 |
| τ_F | 费用分段/取整阈值 | 只在阈值附近数据确实有断点时识别 |
| N_required | 产量/效率对应所需人数 | 上游状态输出，不作为额外自由作用参数 |

优化目标：预测裁员人数、费用及人员结转，提高运营投入和减产候选的利润比较准确性。新增字段是直接监督；基本用工公式以前已有，不把这部分包装成完全未知机制。

### C. 有效工资与班次响应模型：优先，先做派生性核验

新增直接人均工资让我们可以分别校准“需要多少人”和“每人实际要付多少”，避免仅拟合工资总额把两种误差混在一起。它是新增直接观测，不必然是新增独立信息。

候选：`w_eff/w_base=a_w+b_1 max(s−1,0)+b_2 max(s−2,0)`，s为班次利用程度。与既有分班工资公式对照；若w_eff只是原工资/人数的同精度派生值，就不新增自由参数。

| 参数 | 含义和作用 | 处理 |
| --- | --- | --- |
| a_w | 单班基础工资倍率 | 先固定1；有证据再校准 |
| b_1 | 超过一班后的有效工资增量斜率 | 真实平均工资监督；与已有第二班系数对照 |
| b_2 | 超过两班后的追加斜率 | 需覆盖高班次样本 |
| w_base | 当期基础工资 | 当期已知输入，不训练 |
| s或产能利用率 | 班次/加班的工作负荷 | 预测时由计划产量和产能算；实际班次只用于条件验证 |

优化目标：工资及利润预测。检验人均工资×人数能否解释工资总额、不同范围班次误差、整市场/跨回合验证；没有独立提升就保留已有模型。

### D. 人员流动驱动的下一期效率修正模型：研究候选

这是值得检验的新预测假设：招聘与裁员是否携带现有运营模型没有解释的下一期效率变化信息。它不声称人员变动已经被证明造成效率变化。

候选对已有效率模型的下一期对数残差建模：`e_(η,t+1)=α+φ e_(η,t)+β_H h_t+β_F f_t+β_Q d_t`；h、f、d分别为招聘、裁员、辞职人数占期初员工比例。优先单项加入；δ_N固定时辞职率项无独立变化，应关闭β_Q。

| 参数 | 含义和作用 | 处理 |
| --- | --- | --- |
| α | 旧效率模型的持续偏差 | 校准截距 |
| φ | 效率预测误差的跨期持续性 | 有连续路径再估计 |
| β_H | 上期招聘率对下期未解释效率的关联 | 新预测参数候选，不作因果解释 |
| β_F | 上期裁员率对下期未解释效率的关联 | 新预测参数候选，与利用率及运营历史控制项区分 |
| β_Q | 上期自然离职率的关联 | 没有有效变化时不训练 |

必须用历史折外效率残差构造训练标签，不能拿全数据已拟合残差调参后再报告留出。只用预测时可知的上期事件，不能用当期事后裁员预测当期效率。除去初始/练习路径后正式连续回合仍少，本模型需先统计合格正式路径，严格与“不加人员变量”基线比较。

### E. 生产资源—排放联合预测模型：可校准，主要优化新指标

输出产量对应CO2、能耗与用水；初版3个单位系数k_C、k_E、k_W按产品/技术版本区分，零截距线性关系先行。只有独立观察到固定消耗或非线性残差时，再加入α_resource或利用率项β_util。

当前单位强度近乎恒定，所以它适合低参数物理校准与数据质量检查。新增指标预测可直接受益；对利润/需求预测的收益目前主要通过A的历史状态校准，不能宣称其会改善需求或纳入不存在的碳税、水费、能源价格。

### F. 路线排放与物流结构校准模型：次优先

候选：`C_transport=e_TH Q_TH+e_ID Q_ID`；e_TH、e_ID分别为泰国、印尼目的地单位运输排放，可按产品、运输方式和回合条件选择。

| 参数 | 含义和作用 | 当前情况 |
| --- | --- | --- |
| e_TH,e_ID | 两条路线单位运输排放 | 本快照典型复合梁强度3920.50、47084.40 g/单位；仅观察值，不宣称未来不变 |
| Q_TH,Q_ID | 两条路线交付数量 | 上游预测/历史观测；注意输出kg与g换算 |
| α_route | 固定运输排放 | 仅有证据时添加，当前先固定0 |

用途：预测运输排放，利用排放、数量与合计核对国别交付/单位/错配；检查物流约束是否解释真实销量。旧原件已有路线数量，当前若e常数已知，排放与数量只是同一个信息的转换，不应重复塞进销量回归。未观察环境收费或需求作用规则，暂不训练“碳排放→销量”系数。

## 五、暂不训练或不列新增方向

- 不训练“ESG/碳排放提升市场份额”模型：当前生产单位强度没有有效队间变化，总排放主要反映产量；直接用本期总排放预测本期需求/利润存在反向关系和结果泄漏。
- 不训练随机离职风险模型：观察到的10%离职关系与显示误差兼容；未识别随机概率。
- 社会价值分配多为现有会计量的再表达，不用它预测同回合利润。
- 股息/股权现金样本全零，无可识别参数，且当前范围排除股权操作。
- 现金转换/预付款状态模型可以用旧已有资产负债表进一步研究，但不属于本次真正新增字段解锁；仍沿用当前库存、短贷、股权范围限制。
- 连接件当前曲线和前景新增并不意味着有连接件真实结果标签，不能凭此训练需求模型。

## 六、最小实验顺序与验收

1. A先建立历史观测区间和独立渠道核验，不重写原件；检查校准后效率与旧效率参数的差异。
2. B/C利用新人员事件及工资目标做独立子模型，优先核已有规则，再拟合未知残差。
3. 以相同训练/验证划分比较“旧观测”“校准观测”“人员变量”的增量效果；报告人数、效率、解聘费、工资、利润误差。
4. D在连续正式路径够用且无标签泄漏时做探索实验，留整市场并用正式1→正式2路径验证；没有提升就删除新增变量。
5. E/F先做物理校准和新指标预测；只在出现单位强度有效变化及可知前因后研究更复杂响应。

新旧所有版本使用同一数据划分、旧冻结对照和未知对手/行业总量情景；重复图表点及派生指标不增加独立样本数。已经公布的正式2只能做历史复现，不冒充事前预测。

本次结论是可验证的新模型假设和数据证据，并未测出实际预测精度增益。相较前一份规划，本报告将“旧模型升级”与“新数据解锁的新目标/新监督”明确分开。
