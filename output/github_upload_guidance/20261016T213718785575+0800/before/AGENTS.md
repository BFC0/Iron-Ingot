## 采集规则

快速教程已有归档，直接复用，不因切换回合、市场或常规核验而重复采集。仅在用户明确要求、已有归档缺失或损坏、或发现教程内容更新时补采，并记录原因与版本。详细要求见 `Cesim_任务要求与当前情况说明.md`。

## 报告输出

自2026-10-14起，不再采用 HTML 输出报告（report），也不额外生成 HTML 报告副本。默认使用 Markdown；用户指定 Word、PDF 或其他非 HTML 格式时按指定格式交付。历史 HTML 报告和原始网页证据保留。详细交付要求见 `Cesim_任务要求与当前情况说明.md`。

## 决策优化与方案输出

输出决策方案时，全部可控参数须纳入优化，预估项随方案一致重算；不能仅优化部分变量而将其余默认固定。按当回合“决策”下各子页及页内子类、字段的实际顺序用规范Markdown表格完整输出，涵盖当前值、建议值、单位、优化状态及依据。每套方案必须说明假设；有多方案时，按统一基准、期限及情景用表格比较收益、风险、现金与约束，给出推荐理由。缺数据或机制的参数须明确未求解及影响，不能宣称全参数最优。详细要求见[决策全参数优化与方案输出](Cesim_任务要求与当前情况说明.md#决策全参数优化与方案输出2026-10-15用户确认)。
