## 2. 优先训练或校准的模型

### M1 逐产品、逐历史条件的研发响应曲线

作用：把当期研发投入转成需求乘数，避免正式3连接件套用复合梁参数，避免历史曲线覆盖当期曲线。

输入：当期投入R、产品p、市场/阶段/回合、曲线记录的上期实际投入条件h；输出f_R(R|p,t,h)。候选沿用现有幂曲线a_R+b_R(R+c_R)^d_R，与原始点插值对照。

| 参数 | 含义与作用 | 单位/约束 | 是否训练 |
| --- | --- | --- | --- |
| a_R | 曲线纵向偏移，与其余参数共同决定零投入乘数 | 无量纲；整体乘数为正 | 是 |
| b_R | 研发响应幅度；增大表示同投入下乘数变化更大 | 随幂次而定；非负 | 是 |
| c_R | 横轴偏移，控制低投入段形状 | 千美元；正值 | 是 |
| d_R | 幂指数，控制递减速度 | 无量纲；优先0<d_R≤1 | 是 |
| h,p,t | 选择哪条历史条件/产品/回合曲线 | 分类键 | 否，不作为连续系数 |

可先拟合已核验正式3三条曲线中的两条研发曲线；历史重训还需对应历史曲线及上期投入。不能将已条件化曲线再输入R+0.5R_prev而不核查重复计入。点留出检查插值误差、单调性、正值与范围边界；曲线点拟合误差和实际需求误差分别报告。

### M2 研发本期与下一期作用模型

作用：评估本期研发的即时收益与延期收益，修复固定0.5滞后代理未经识别的问题。

输入：当期及上期实际研发、匹配曲线、价格、国别营销、真实需求与完整竞争组。候选是在竞争得分中分别设置当期与上期响应项，而不是先把投入任意相加。

| 参数 | 含义与作用 | 约束/边界 |
| --- | --- | --- |
| β_R,now | 当前研发响应对需求竞争得分的作用 | 按国家/产品识别；曲线已表达全部作用时可固定而非重复拟合 |
| β_R,next | 上期研发对本期需求的延期作用 | 仅在曲线历史条件之外仍有可辨识作用时加入 |
| ρ_R | 旧有效投入模型中的延期权重 | 仅作为旧模型对照；0.5不是已知平台常数 |

β_R,now、β_R,next与曲线形状不能在同一小样本里无约束同时估计。先固定核验曲线，再比较有/无额外延期路径；不能同时把β_R,next和ρ_R都当自由参数。需要完整两期路径及不同研发策略；已有资料支持研究，尚不能保证分离识别。做投入一次、以后为零的脉冲检查，验证本期和下期需求/利润都有路径；不擅自推到永久累积。

### M3 运营累计状态与生产效率模型

作用：让更早运营投入进入后续效率、人数、工资及利润，而不是第二个后续回合突然丢失。

候选状态S_t=δ_O S_(t−1)+O_t；曲线f_O=a_O+b_O S_t/(c_O+S_t)；效率η_hat=k_(国家,产品,技术版本)×f_O。这是待检验结构。若平台曲线已以历史累计状态为条件，应直接使用条件曲线，不能再把同一历史状态加进横轴。

| 参数 | 含义与作用 | 单位/约束 |
| --- | --- | --- |
| a_O | 基础效率乘数 | 无量纲，非负 |
| b_O | 可提升的饱和幅度 | 无量纲，非负 |
| c_O | 达到该幅度一半所需的状态规模 | 千美元，正值 |
| δ_O | 历史运营状态保留比例 | 首先用1作不衰减基线；0≤δ_O≤1只是候选范围，衰减需证据 |
| k | 技术尺度，将乘数转换为实际效率 | 千单位/人；优先读取已知技术参数，未知时再校准 |
| S_0 | 初始运营状态 | 从历史构造；未知不得填零或与k、a_O同时任意拟合 |

数据：运营历史、真实生产效率、产品/工厂、曲线历史条件。先拟合当期曲线，再固定形状检验状态和尺度，避免参数混淆。缺连续历史的路径不进入累计训练；练习2不结转到正式1。验证连续至少三期、单次投入后的持续路径及跨期效率误差。

### M4 国别、产品独立的竞争需求模型

作用：预测各队真实需求，为产能分配与定价提供输入。先升级现有softmax份额模型，暂不另建复杂黑箱。

u_i=−ε ln(P_i/P_ref)+β_G ln(1+G_i/K_G)+β_H ln(1+H_i/K_H)+研发响应项；s_i=exp(u_i)/Σ_(j∈本市场竞争组)exp(u_j)；D_hat_i=T_hat×s_i。

| 参数 | 含义与作用 | 处理 |
| --- | --- | --- |
| ε_(国家,产品) | 相对价格得分系数，越大表示模型中高价惩罚越强 | 训练；不是直接的绝对需求弹性 |
| β_G | 本国一般营销的条件响应 | 训练；不再默认使用两国合计代理 |
| β_H | 本国设计师营销的条件响应 | 训练；与一般营销分开 |
| β_R或M2两项 | 研发响应对竞争得分的映射 | 训练/固定择一，避免重复作用参数 |
| κ_P | 高价段追加惩罚 | 可选；仅高价样本覆盖且留出改善时训练 |
| P_knot | 高价分段位置 | 候选配置；从训练折覆盖范围选，不固定宣称1.5倍为规则 |
| P_ref,K_G,K_H | 参考价、营销尺度 | 已知/固定特征尺度；K=1000千美元可作旧模型对照，不冒充作用系数 |

每国每产品基本4个作用系数，含高价项时5个；采用M2双研发项时相应增加1个。完整竞争组才计算归一化；共享系数不把不同编号市场混成竞争集合。四项销售页乘数保持给定输入/待核字段，不单独训练四条响应曲线。营销滞后目前没有充分机制证据，暂不新增参数。

复合梁已有历史真实需求，可先构造合格训练集；连接件当前只具备曲线与前景，真实需求模型需等结算标签。使用实际行业总量和已知对手决策的条件回算，必须与预测行业总量、未知对手情景下的事前预测分开。

### M5 国别、产品行业总需求模型

作用：预测T，补上份额准确但行业规模错误造成的公司需求误差。

先比较上一期总需求持平、前景增长区间和单增长系数三个基线。T为同市场同国同产品各队真实需求之和，不用销量合计替代。

| 参数 | 含义与作用 | 处理 |
| --- | --- | --- |
| g_(国家,产品,情境) | 行业需求增长率 | 每可比情境先只估1个参数；新产品无历史基数时不可直接套增长率 |
| α | 对数增长截距 | 仅扩展增长回归时与g方案择一 |
| β_avgP | 行业平均价格变化与总量的关联 | 后续候选；不能用当期未知对手真实价格做事前特征 |
| β_avgM | 行业营销变化与总量的关联 | 后续候选；宏观样本数不足时关闭 |

行业训练单位是市场×国家×产品×回合，不是团队单元格；同市场10队不能算10个行业独立样本。目前历史回合少，先保持低参数模型，不把前景文字5–10%变成确定实绩。留整市场和下一已结束正式回合验证；新产品使用显式规模情景。

### M6 用工、班次及工资校准模型

作用：区分效率误差、班次误差与工资参数变化对利润的影响。

输入：实际产量q、产能C、效率η、期初人数N_0、实际班次/员工人数、当期工资表。先核N≈q/η及分班工资等式，未知残差再拟合。

| 参数 | 含义与作用 | 处理 |
| --- | --- | --- |
| w | 基础人均工资 | 当期已知；正式3归档为30千美元/人，不沿用旧28 |
| κ_2,κ_3 | 第二、第三班工资乘数 | 优先给定参数；只有未解释差额时校准 |
| τ_1,τ_2 | 产能利用率班次切换点 | 先检验旧C/3、2C/3；不是未经确认的固定规则 |
| δ_N | 自然离职率 | 优先给定；不足时用前后员工/辞职实绩校准 |
| σ_F | 解聘补偿比例 | 优先给定；用裁员费用核验 |
| 人数取整方式 | 决定边界处人数和费用 | 离散规则候选，不拟合成连续系数 |

新增生产人力/明细数据直接支持本项。保留班次阈值附近样本和一个完整未参与校准回合；预算试验仅检验预算关系，再用实际工资、人数及费用验证。多产品工资分摊需合计守恒，不擅自假定人员可无成本通用。

### M7 原材料单位费用模型

作用：提高材料成本预测，并判断已发现小差额是稳定比例还是旧回合特例。

候选C_material=q×v_t×(1+γ)；与公布价直接计算、固定单位差额两个旧候选对照。

| 参数 | 含义与作用 | 处理 |
| --- | --- | --- |
| γ_(产品,条件) | 公布材料单价到实际单位费用的比例校正 | 训练，初版每产品1个；不同时自由拟合比例和截距 |
| v_t | 当期公布单价 | 已知输入；连接件正式3归档14.2美元/单位 |
| q | 真实生产量/预测生产量 | 条件验证用实际，事前预测用上游输出 |

旧复合梁γ=0.0013798365756只作冻结对照，连接件不能继承。按总费用残差拟合，保留显示舍入区间，不对低产量反算单价等权。已有正式2实际子集可用于进一步验证，但须先对齐产量、材料费用和当期基准价，不再沿用旧报告“正式2无标签”作全项目现状。

### M8 实际贷款利率与计息机制

作用：预测财务风险加点，并区分风险函数误差和计息时点误差。

先沿用两种2参数候选：r_L=r_base+a_r((L+L_S)/E)^b_r，或r_L=r_base+a_r exp(−b_r E/A)。两种择一，不叠加。

| 参数 | 含义与作用 | 处理 |
| --- | --- | --- |
| a_r | 风险溢价幅度 | 训练，非负 |
| b_r | 风险对杠杆/权益率的非线性敏感度 | 训练，正值 |
| r_base | 当期基准年利率 | 已知输入；正式3前景5%与表格4%冲突未解，暂分情景 |
| Δr_S | 短贷利率相对长贷加点 | 当期给定；不建自动借还机制 |
| θ_I | 若规则未明，期初/期末债务对计息余额的权重 | 后续单独识别候选，不与风险函数一次盲拟合 |

条件验证可使用实际期末E/A/债务；事前预测必须使用财务联立预测状态。训练和调用处理非正权益、资产及超训练范围，不能直接幂运算或静默外推。当前简化范围排除自动短贷；如路径触发该机制，标超范围，不能报完整利润。

## 5. 训练配置、验证与落地顺序

作用参数、已知条件、状态、训练配置分开存储。建议初始配置如下；均为规划值，不是已选部署配置。

| 配置 | 初始方案 | 作用 |
| --- | --- | --- |
| λ | 0、0.0001、0.001、0.01、0.1、1 | 非负/岭惩罚强度候选，只在训练折选择；统一损失尺度后才比较 |
| 特征标准化 | 仅用训练折计算尺度，预测反变换 | 避免量纲影响惩罚与留出泄漏 |
| 模型复杂度 | 先基本项；高价、延期、额外状态参数需留出改善与可识别性 | 防止小样本多参数拟合 |
| 样本权重 | 同国/同产品内整市场等权，重复单元格去重 | 避免补采多的市场因行数多获得额外权重 |
| 共享范围 | 按用户同期共享假设训练同国模型；不同产品/技术/历史条件分别核验 | 不把共享假设扩展为跨期参数不变 |
| 划分 | 外层留整市场；内层选参；另做正式1训练→正式2已结束回合验证 | 分离同回合泛化和跨回合迁移；时间顺序用历史复现，不能冒充事前冻结成绩 |
| 图表划分 | JSON/SVG同点去重后统一划分；完整曲线/历史条件留出优先 | 防止同点和同曲线信息泄漏 |

需求指标：份额MAE（百分点）、真实需求MAE/WAPE；零需求不直接取log，WAPE总分母为零时标不可算。行业总量误差与份额误差分开。效率：MAE/相对误差和连续路径误差；成本/利润/现金：千美元误差及逐项来源；利率：基点误差。舍入容差、条件残差带和预测不确定性分别报告。

冻结预测先评分，后重训。验收分三层：①给定真实上游输入时的组件回算；②给定历史期初和已知条件时的整链历史预测；③决策时未知总量/对手/期末状态下的冻结事前预测。第一层准确不能宣称第三层准确。

顺序：

1. 对齐训练单元格、来源身份、产品、国家、阶段、回合和生效决策；逐模型统计合格样本与连续路径。
2. M1与M3当期曲线拟合/接入；再识别M2研发延期、M3运营累计状态。
3. 用新增人力与财务数据核M6、重验证M7/M8；接通多产品交付、订单和财务状态。
4. 重训M4复合梁国别需求与M5行业低参数模型；连接件需求暂作场景，等待真实标签。
5. 正式1→正式2历史复现与独立验证；保存新版本，旧冻结版本保留。
6. 连接逐期状态，到正式6比较累计收益；提供完整决策项候选与风险场景。

优先级依据是流程缺口和新增数据可支持的程度，并未量化哪项能降低多少误差。本次未新增训练参数、未跑旧训练脚本、未进行平台试验。
