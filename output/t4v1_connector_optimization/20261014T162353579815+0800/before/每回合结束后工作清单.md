更新：2026-10-14（北京时间）。适用于正式第t回合截止结算后的复盘与交接，t为1至6。结果尚未公布时，先归档截止决策与冻结预测，将结果相关事项标记“等待公布”；截止或保存决策本身不代表已取得实际结果。

历史逐栏覆盖已达750/750页，范围截至正式2；正式3结算归档另建覆盖矩阵，不计入旧750页。同期HTML内容冲突与财务待核仍单列。最新依据见[README](README.md)。下面是完整复盘规范，不表示这些步骤都已执行。库存/生产策略、自动短贷和股权变动按当前简化范围标记限制；流程保留可见实际记录，不把范围外缺口列成当前修复任务。

## 1. 归档范围与打印优先采集路径

**每个已结束回合必采“决策 → 决策列表”的历史小组列。** 通过页面回合选择器选择刚结束的回合，核对历史回合提醒、课程、市场和团队；保存完整HTML、表头、单元格样式、全部决策与预估字段、零值、默认值和选择项。小组列作为历史提交方案来源，个人列分别保存，预算摘要另标预算，不能当实际利润。与结果页可见价格、投入、产能分配等交叉核验，并保留每项源行列与哈希。历史方案无法读取时仍标未知，不用个人草稿或候选代替；既有历史回合缺少决策列表的，补采并建立独立覆盖清单。

2026-10-13用户发现：在决策列表切换历史回合后，决策中的其他子栏也随之切换到该回合。补采历史前景、需求、生产、销售、物流和财务时，先在决策列表选回合，再逐页确认历史回合提醒及本人区域；需要时回到列表再次核对。**其他决策子栏的可编辑值仍是个人区域输入；本组提交值读取决策列表中的“营销团队”列。** 个人输入、玩家预估、个人预算、历史小组方案、实际结果分开标记，不能把其他子栏个人值拼接成小组最终决策。历史曲线保留对应回合与页面显示的上期实际条件，前景说明与可编辑决策值也分开。

按用户指定，补采的“营销团队”列输入统一标为“回合k小组最终决策”，练习期保留“练习回合k”前缀；其中玩家预估仍保留预估属性，预算摘要另标“回合k小组历史预算摘要”。标签包含阶段和回合，不能将预估或预算当成实际终值。

历史缺口补齐后同时采集下一开放回合已知条件和初值。本次为正式4：保存前景五部分、参数及曲线，逐字段核对正式3期末与正式4期初的现金、债务、资产产能、人员、库存、税亏及订单承诺；页面显示的上期实际投入作为条件单列。当前个人输入和小组当前草稿另标基准快照，正式4未截止时不得标“回合4小组最终决策”。缺失初值保持未知，不用上回合个人草稿或假设代替。

**2026-10-14用户更新：结果采用“先采可打印版 → 优先计算可推导缺项 → 网页定向补采剩余缺口”。计算公式须在交付文档说明，数据明确标为“计算值”。本流程替代此前每次必须打开全部结果子栏的要求；数据范围、精度和来源核验保留。** 每个市场、阶段、回合单独完成以下路径，再切换下一个市场，避免重复切换选择器。

1. 在规范结果页选择并核验市场、历史回合及团队顺序，通过实际可见链接打开可打印版本；保存完整HTML、数表、说明、URL、时间与哈希。打印页若无选择器，保留打开前的选择证据，并用概要利润、累计收益及团队队列与来源页核对；不能只凭文件名认定回合。打印页失败或内容不完整时，回退到对应网页数表，不补零。
2. 先从打印版建立字段索引，包含表格/分区、团队、国家、产品、单位及源行列。参考同产品、同页面结构的已核网页对照，生成缺口清单；只规范化空白和帮助符号，标签别名必须经语义与数值核对。打印版已有的价格、国别需求/销量、工资、订单、库存、三表、财务指标及价值创造不重复逐页采表。
3. 对打印版缺项先使用下文公式计算；已有有效同回合原件也可复用。输入齐全、口径已核且计算精度满足用途时，登记“计算值已补充”，跳过仅为取得该字段而打开的网页。无法推导或计算精度不足的剩余缺口才按下表补采。需要打开的每页一次性保存完整HTML、所有数表、可见说明、图表初始化JSON及内联SVG，避免为同页不同字段再次导航。只读当前页面已收到的数据，不执行页面脚本或调用隐藏接口。

### 打印版缺项的计算公式与标记

计算使用Python，保留可复现代码及输入来源。以下公式仅用于缺项补充；打印版已有直接值时保留直接值，不用计算覆盖。所有输入必须属于同一市场、阶段、回合及正确的团队/国家/产品，零值须有原件。单位和业务范围一致后才求和，缺输入、分母为零或列归属不明时标未知并定点补采。

| 可优先计算的缺项 | 计算公式 | 口径与条件 |
|---|---|---|
| 团队某产品跨国需求/销量总计 | `总需求 = Σ国家需求`；`总销量 = Σ国家销量` | 包含全部销售国家；订单是否另列按平台定义，不能重复计入；不同产品的千单位不直接合并 |
| 某产品整体市场份额，% | `100 × 本队该产品跨国销量 / Σ全部团队该产品跨国销量` | 与网页销量份额定义及销售范围一致；用销量而非需求，不能简单平均国别份额。多产品整体份额须先确认数量或金额计量，不能沿用单产品公式 |
| 总流动资产，千美元 | `成品库存账面价值 + 应收帐款 + 现金及现金等价物 + 其他流动资产项目` | 加齐当期表中全部流动资产；库存数量不能当账面价值，也不能把“资产总计”重复相加 |
| 净现金，千美元 | `现金及现金等价物 − 短期贷款` | 沿用已核打印表定义，不擅自扣长期贷款 |
| 每人平均工资，千美元/人 | `同生产国生产工资合计 / 同口径当期生产人员数量` | 分母为公司在该生产国全部生产人员；多产品人员须确认互斥且可合计，不能只用某产品人工数量配公司工资 |
| 人员净变化，人 | `本回合人员数量 − 上回合人员数量` | 上回合输入来自同阶段上一回合的已核打印原件；结果只称“人员净变化”，不能称招聘/裁员人数。只有辞职数独立已知时，才按辞职带符号值计算 `招聘/裁员净额 = 本期人员 − 上期人员 − 辞职变动` |
| 产能利用率，% | `100 × 同产品实际产量 / 同产品可比可用产能` | 分子分母对应同生产国、产品及当期；机器名义产能和实际可用产能不能混用，平台口径未确认时不替代网页指标 |
| 累计收益的缺失期间值，千美元 | `已核阶段起始累计收益 + Σ该阶段起始以后至本期的各回合利润` | 必须有真实起始基准和每一期利润；练习/正式分开，正式1回到初始基准，不能继承练习2。起始基准不默认零，不能以当期值重建未知历史 |

每项计算结果在Markdown/HTML/表格中标为“指标名（计算值）”，JSON/CSV至少保留 `value`、`value_type=calculated`、`formula`、`unit`、完整业务键、`inputs`（各输入值、原件路径、SHA256、表格/行列）、`precision_note` 和计算代码路径。交付文档附本次实际使用公式及适用条件；计算值、直接采集值、预算和模型预测分别保留类别。后续网页直接值另存用于交叉核验，不改写原件或抹去计算来源，同一指标的两种表示不计两个独立样本。

打印数值已舍入，计算结果不能恢复平台内部精度：求和/差值的保守显示误差上界为输入半步误差之和；比值在分母区间严格为正时，按输入区间的端点计算范围。显示舍入方式未确认时，半步区间标为近似假设，保留原始显示位数，不凭Python输出小数位数声称高精度。报告计算值可能与网页末位有差异；模型确需平台原始精度、分母区间含零或差异超出容差时再补采对应页面。

生产环境/运输排放缺少当期有效单位强度时不能只凭产销量计算；单位强度仅取已核当期原件，不默认沿用旧回合系数。辞职、招聘、裁员比例、产品/订单收入拆分、股息及发行/回购明细不能从净变化或总额唯一推导，仍定点补采。历史图表可在全部期间打印原件齐全时生成“计算值/打印值重建序列”，但不能标为平台原始图表JSON；所需原始精度和独有序列仍须采集。

### 剩余缺口的网页补采顺序

| 顺序 | 页面 | 补充内容与进入条件 |
|---:|---|---|
| 1 | 生产→环境 `productionenvironmental` | 打印未包含的CO₂、能源、用水总量及单位强度；两产品、各生产国分别保留 |
| 2 | 生产→人力资源 `productionhr` | 先计算人均工资并复用已核上期人员；仍缺辞职、招聘/裁员、裁员比例或所需原始人员序列时补采；已有当期人员和工资交叉核对 |
| 3 | 物流→排放 `logisticsemissions` | 路线排放、合计及单位销售强度 |
| 4 | 概要 `summary` | 打印未包含的历年收入、利润、累计收益序列及图表原始精度；只有对应全部序列已在打印原件中保存并核验时才跳过 |
| 5 | 市场→明细 `marketdetails` | 先计算跨国总需求、销量及口径已核的整体份额；产品维度、其他字段或精度仍有缺口时采集；计算项标“计算值” |
| 6 | 财务→损益表、资产负债表、现金流量表 `incomestatement` / `balancesheet` / `cashflow` | 流动资产小计优先计算；产品/订单收入拆分、股息及股票发行/回购现金流等不能唯一推导的缺项补采；逐表判断，不因缺一表就重采三表 |
| 7 | 生产→明细 `productiondetails` | 打印缺产品机器产能、分产品用工/成本/效率或单位时采集；新增连接件等产品不能套用单产品清单 |
| 8 | 市场、生产、物流图表及价值创造 `market` / `production` / `logistics` / `societalimpact` | 已有高精度图表要求，或存在打印/补采数表不能替代的指标、维度、序列时采集；模型训练所需原始精度不能用打印舍入值代替。相同数值的重复图形不另作独立数据 |
| 9 | 物流明细、财务指标 `logisticsdetails` / `ratios` 及其他实际导航子栏 | 打印字段缺失、单位/团队/产品无法配对或出现内容冲突时定点补采；已被打印原件完整覆盖则登记复用 |

首次遇到新页面结构、新产品/国家或新增子栏时，做一次完整网页对照并保存新的字段/图表缺口清单，再用于同结构市场；不能将练习2单产品清单直接视为正式3双产品完整清单。后续发现空表、未知字段、选择错配、财务不平或打印/网页差异超出显示精度时，先重核选择与内容，再仅补对应页面；无法确定影响范围才回退全栏对照。旧缺口或拒绝来源不会因采用新路径而自动关闭。

2026-10-14补采已观察到：不同对话的独立标签页切换结果市场会影响另一个页面返回的选中市场，错配页已在保存前拒绝。因此平台结果采集按任务轮流独占，每次交接先重新打开规范结果栏目URL，再选择并核验市场和回合，避免旧页面事件链接继续返回旧选择；每页再查选择器、URL栏目及内容。离线解析、哈希、财务和曲线核验可并行。多标签页不视作市场选择隔离，不能只凭请求URL或文件名认定归属。

每页保存当前选中的市场、阶段、回合、栏目、来源URL、采集时间、完整表格及可见说明；所需图表同时保留可取得的内联数据和SVG。覆盖清单按“市场×阶段×回合×数据类型/字段/所需图表序列”验收，逐项标记打印已覆盖、计算值已补充、网页补采、同回合已核原件复用、未采集、不可访问或不适用，并指向具体原件、表格/行列或图表ID及哈希；计算项还须附公式、输入和精度说明。未访问的子栏不能标为逐栏已采；未采集不能视作无数据；当期页眉不能代替历史结果选择器。原件排他创建，输出保留单位、团队顺序和来源哈希，人员展示统一用首字母。累计序列保留练习/正式阶段边界，打印、计算及网页重复表示不重复计入独立样本。

本要求追溯补全此前所有遗漏：沿用已授权市场1–10范围，覆盖初始0、练习1/2、正式1/2及今后已公布回合；已验收且哈希有效的同回合原件直接复用，不重新采集。身份、页面内容、字段和所需序列覆盖均通过，且无未解决内容冲突，才能标记新路径的数据归档完成。历史750/750及正式3的15栏覆盖统计、固定15栏验收脚本保持原定义；新路径不能将打印页虚算为15个网页或直接送入旧验收后宣称全栏通过。新批次报告同时记录打印/补采页数、字段/序列覆盖、剩余缺口及浏览器耗时；速度收益以实际同范围记录为准。

## 2. 结算后的执行顺序

| 顺序 | 应做的事 | 必须保存的产物与完成标准 |
|---:|---|---|
| 1 | 确认本回合确已结算，实际结果已发布；核对课程、市场、正式回合及本组身份，记录下一回合状态和截止时间 | 结算与选择证据。逐页核对实际选择和结果标题；不能只凭文件名或旧网页状态确认回合。未公布则标记等待，不把预算当实际。 |
| 2 | 归档本组最终生效决策、实际结果、回合前景与曲线，以及同编号市场内各竞争组的可见实际决策和结果 | 原始快照/附件及来源清单、时间、单位、哈希。覆盖国别需求、销量、价格、营销、研发、运营、生产、效率、库存、订单和财务三表等可见项；不可访问项单列。按授权范围采集其他市场，各市场独立定位。实际生效方案无法取得时记录缺口，不用个人草稿冒充。 |
| 3 | 核验结构化数据及分类 | 唯一键包含市场、阶段、回合、团队、国家、类别；需求、销量、玩家预测、预算和模型预测分开。检查缺失、重复、单位、数量守恒、财务平衡及累计值；按显示精度保留误差，不强行改原始数字。保留原冻结模型、预测、输入和最终方案对应关系。 |
| 4 | **先评分原冻结预测，再接触重训** | 用Python生成原预测与实际逐项对照、误差和适用范围。需求按国家比较份额及绝对需求，销量、效率、利润、现金等只评分实际已冻结的对应项。缺预测或最终方案不同则注明不可直接评分，不事后补造事前预测。使用已实现对手或行业总量的条件回溯另列，不能并入事前成绩。 |
| 5 | 分析偏差与经营结果 | 区分决策变更、行业总量、竞争份额、供给限制、效率、成本、融资税费、情境变化及数据精度。对照“模型预测—平台预算—实际”时分别解释口径；销量不足不自动当需求不足。解释当期利润、累计收益、现金及债务变化，不能用现金增长替代收益。原因只能作为有证据支持的诊断，关联不冒充因果。 |

## 3. 状态结转核验

- **研发与运营：**上一回合实际投入与完整持续存量分开；历史ρ或有效投入代理不能自动当成已验证存量。营销延续同样须有依据。

- **订单与库存：**结转未交付承诺和库存数量、账面价值；记录订单报价、币种、交付期、收款及履约条件。数量为零须有来源，缺失不能补零。
- **债务与税亏：**长短债本金、利率、利息、还款及税亏余额分别核对。还本不能直接当费用，利息不能与本金重复扣除；亏后转盈和自动短贷仍需实际规则或有效样本支持。
