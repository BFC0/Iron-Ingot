## 历史情境重审入口与输出

## 阶段选择与个人试验

`--stage` 可选 `all/audit/fit/budget/stress/search/report`；各阶段均重建审计和情境记录，`report` 仅生成该次基础审计报告，不重用历史拟合结果。
实时捕获是历史证据；再次操作 Cesim 前须重新核验身份、回合及个人基准。机器试验已恢复，当时因其他成员列变化停止后续扰动。用户2026-10-11明确：其他组员各自个人列的修改不影响本人的决策及预算数据，不能仅据此停止试验或排除样本；以本人列、本人输入页和本人预算核验。历史样本仍须检查身份、保存及预算来源后才可用于验证。
