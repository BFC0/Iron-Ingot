1. **先读后算。** 阅读规则、案例、市场前景、全部可见已知数据及历史结果，再拟合、验证、优化、填写。
2. **所有预测及财务计算使用 Python。** 每个预测值说明模型、输入、参数来源、拟合方法、适用范围及不确定性；每个计算值提供公式、单位及来源定位。保存代码副本，保证可复核。
3. **每项决策有数据理由。** 同时考虑需求、价格、营销、研发、运营、产能、投资、班次、解聘、物流、融资和最低现金；比较当前方案、候选方案及不利情景。有限网格最优或预算提高不等于六回合累计收益最优。
4. **原件可追溯。** 保存网页可见资料、附件、截图、快照、源行列、市场/阶段/回合/团队/国家、单位、采集时间和哈希；不可访问的资料写为缺口。失败采集和无效试验保留并标记，错配资料隔离于 quarantine。
5. **数据类别分开。** 已公布实际结果、已知参数/历史决策、当前决策输入、玩家预测、平台预算、模型预测分别处理。销量受供给截断，不能代替真实需求；预算依赖手填需求，不能当需求训练标签；缺失不补零。
6. **回合状态正确。** 正式1从初始0开始，不继承练习2资金、债务及亏损。练习1与正式1可见前景34行一致，只证明可见资料一致；练习2与正式1跨回合差异不能证明隐藏函数变化。
7. **竞争与迁移。** 暂按用户指定假定编号市场间无直接作用，同编号市场内小组竞争仍存在；假设尚未证明。A只用市场5训练，B按市场等权共同训练，参数分别保存；共享系数不表示跨市场需求传导。
8. **验证不混用。** 调参限于训练数据；记录留出范围、已实现对手策略和实际总量诊断。冻结未来参数与预测，正式结果公布后先评分原冻结文件，再重训；事后条件回溯误差不包装成事前成绩。
9. **网页改动遵守个人区域授权。** 最新归档为市场5、营销团队、PYT个人区。允许的临时试验结束后恢复试验前最新基准；用户明确保留的值继续保留。输入后检查派生变化、个人列及重入回读。个人保存不等于小组提交，不覆盖其他成员。
10. **当前整理不恢复决策填写流程。** 此前归档/建模已按后续指令继续，推荐值填写仍待用户恢复；跨市场流程限定只读，不修改、导入或提交，不联系其他小组或教师。此前授权不能扩大为小组正式提交。
11. **交付可阅读。** 说明只保留关键内容及来源关联，避免重复归档数表；Word公式使用可编辑内置公式，中文宋体、英文 Times New Roman。

### 版本隔离与统一口径

- 使用独立分支`codex/model-v2`，不创建额外工作树。先保存当前已修改及未跟踪文件的内容快照、Git状态和哈希，不清理、重置或丢弃已有工作。
- 新实现放入`code/model_v2/`；每次运行写入`output/model_v2/<北京时间运行编号>/`，不得覆盖此前运行。原始归档、旧结果、正式1冻结参数及预测作为只读基线；不得直接运行现有脚本中会覆盖结果、更新旧索引或哈希清单的主入口。
- 每次运行保存代码版本、输入哈希、训练键、数据截止点、参数、单位、情景假设与检查结果；运行前后核验受保护文件哈希。不自动更新旧版latest。
- 所有预测与财务计算使用Python。数据唯一键包括编号市场、阶段、回合、团队、国家和数据类别；实际需求、销量、玩家预测、预算和模型输出分开保存，缺失不补零。
- 数量使用千单位、财务金额使用千美元、单位价格使用美元，利率内部使用小数。已知参数关联当期前景来源，经验校准项单独标记。
- 同一套函数供单项核验、完整计算链、搜索和报告使用。新增只读运行入口，支持数据核验、拟合比较、预算回算、压力测试、决策搜索、报告六个阶段。

### 四阶段执行与验收门槛

1. **统一口径。** 统一数据、单位、损失归一化、参数与模型版本；需求采用市场等权平均损失，特征尺度仅从当前训练折计算并保存逆变换。证明残差总和与平均损失在对应调整惩罚后参数一致；复现旧冻结预测及预算回算，差异解释后再进入下一阶段。
2. **需求、曲线与效率。** 旧A/B为基线；比较原始与标准化惩罚、单一与分段价格作用，分段点固定为对应初始价格的1.5倍。检查删队/删市场、极端价格、投入相关性、系数边界与零需求；核对零值显示精度，不任意加小数。国别投入缺失时保留合计代理，不据此优化国别分配。研发与运营延续分别测试并重新拟合；曲线范围内外分别评价，标记投入及联合策略外推。效率处理产量/人数舍入，重点核验400投入附近和重复策略影响。
3. **生产与财务。** 先核对来源，再做可恢复个人预算单变量试验；核验班次、解聘、机器投资、折旧、运输、贷款、利息、税、周转和最低现金。保留两种风险函数的稳定性与外推比较，按舍入区间诊断材料差额，纠正既有单位说明。短贷、税亏、库存、大客户、厂房时序分别判定适用范围，不拼出未识别的完整利润。
4. **联合比较。** 前三阶段完成后才粗筛、细化并压力测试；保留不同经营方案，合并结果等价候选。当期比较通过后再做至正式6的条件滚动分析；未来输入缺失使用显式情景，状态结转不完整时不输出完整累计收益排名。

参数选择限于训练内留出，采用市场及国家等权的留出误差；误差相差不超过1%时优先参数更少的模型。练习2只作相同信息条件回溯比较；已参考练习2设计模型，新版成绩仍标为回溯研究，正式结果另作外部验证。稳定性不足或外推未验证的模型仅保留作情景，不作确定推荐依据。

### 全面压力测试

覆盖A/B及新版领先模型、初始0/练习1/练习2对手策略、竞争降价与增加投入、两国分别及同时需求下降；同时覆盖正则候选、研发/运营延续、分段价格、极端样本、曲线外推、效率、班次/解聘、产能不足、材料/运输、两种风险函数、利率、回款延迟、还贷、短贷及跨回合状态。

- 初始档位：需求±10%、±20%、-30%；效率±0.005和±0.01；成本±5%和±10%；利率增加0.5和1个百分点；应收天数30/45/60。均标明历史证据或假定来源，不能伪装为官方参数。
- 确定性测试包括单因素、关键两因素组合与组合不利情景。每个最终候选另做固定种子的2000组分层范围抽样，覆盖多因素同时变化；抽样范围及生成方法保存，避免无意重复施加同一需求冲击。
- 检查利润、现金、短贷、交付、库存、权益及期末状态。未完整计算的分支标记范围外，不按完整利润排名。
- 抽样失败占比与分位数仅描述测试集合，不称为真实概率；情景区间不称为置信区间；测试最小值不称为全部可能情况的最坏值；现金达标不代表保证盈利。

## 标准流程

| 顺序 | 工作 | 产物与验收 |
| --- | --- | --- |
| 1 | 确认课程、市场、回合、截止时间和个人区域；读取最新状态 | 时间戳快照与个人/小组对照，防止旧档覆盖成员改动 |
| 2 | 阅读并增量归档规则、案例、前景、历史实际、决策和预算 | 原件、截图、来源、类别及覆盖缺口 |
| 3 | 结构化输入，区分需求/销量及各类预测 | 唯一键、缺失检查、数量守恒、财务平衡、源单元格核对 |
| 4 | 分步建模 | 行业规模→竞争份额→需求→效率/产能/用工→交付→收入/成本→利息/税/利润/现金 |
| 5 | 回算、拟合、留出与敏感性分析 | 独立记录预算误差和实际需求误差；保留未识别项 |
| 6 | 在个人区授权范围内做有效单变量预算试验 | 成功保存、完整相关预算、恢复与重入核验；无效输入不作校准 |
| 7 | 联合比较经营与融资策略，滚动考虑剩余正式回合 | 推荐表逐字段列当前值、建议值、公式/模型、来源、理由、约束及不利情景 |
| 8 | 恢复填写流程后填入个人区，逐字段回读 | 前后快照、完整平台预算与本地模型对照；小组提交另行协调 |
| 9 | 实际结果公布后先评分冻结预测，再更新模型 | 国别需求/份额/销量/库存/利润及竞争残差，滚动下一回合 |

数量为千单位；财务金额为千美元；价格与运输等单位单价为美元/单位。增长及利率计算使用小数，网页按字段显示百分数。
