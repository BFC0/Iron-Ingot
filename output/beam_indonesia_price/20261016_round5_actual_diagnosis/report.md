# 印尼复合梁高售价：回合5实绩与当前模型诊断

2026-10-16，北京时间。检查当前t6v1n（冻结t6v0需求参数）及已保存正式6两候选。仅离线诊断，不修改模型、候选、真实数据或平台输入，不输出新决策方案。

结论：回合5的高价需求预估确实明显过高；当前重训模型已基本复现该实际点，不能把旧预测的50.9%误差直接归给新版。当前约2508美元的推荐仍缺乏可靠的因果响应和跨回合验证，尤其是营销、研发代理的应用和旧市场价格压力覆盖，需要优先修正。真实结果证明2759美元下份额很低，尚不能单凭这一观测识别2508美元下的实际需求或利润最优价。

## 2. 当前最明确的结构问题：公司费用代理被用于细分决策响应

训练输入是每家公司两产品、两国家合计营销和研发费用。正式6应用仍把六个产品/国家的一般营销相加、设计师营销相加，随后把两个合计用于所有市场。

已作可复现反事实：将中性候选印尼梁设计师营销1298千美元全部移到泰国梁，其余不变，公司营销合计不变，六个产品/国家的预测需求完全不变。模型因此不能识别印尼营销撤空的损失，也无法证明当前细分分配可支持预估份额。新菲律宾营销还进入同一公司总量，可能被计为对泰国、印尼的需求收益；这不是已验证的跨国营销机制。

研发的训练/应用定义也不同：训练使用`公司合计研发+0.5×上期公司合计研发`，应用却用单产品当期及上期研发的曲线比值去改变本组吸引力。中性候选连接件研发增加100千美元，印尼梁需求完全不变；训练中的公司合计研发代理却会随之变化。这是解释变量口径迁移，不能把研究关联直接当作单产品边际收益。

这两项不证明收益必然被高估，但足以说明现有投入组合不能作为高价需求已获验证的依据。[应用代码](../../../code/model_v2/t6v1.py)；[训练代码](../../../code/model_v2/t6v0_demand.py)。

## 3. 价格下降响应已修正，但曲线形状与外推仍缺验证

当前印尼梁份额公式为`自身吸引力/(自身吸引力+九对手吸引力)`，其中价格吸引力按`价格^(-1.977238)`变化。中性候选处的局部需求弹性为1.8431。整市场留出十折的价格系数约1.8914—2.0786，是条件稳定性信息，不是置信区间，也不验证跨回合或同一公司主动调价的因果效应。

这一规格没有高价分段或消费者拒绝价格门槛；只要价格有限，模型就保留正需求。实际存在软门槛或更强高价敏感度时，光滑曲线会高估高价尾部；目前数据尚未证明具体门槛数值，不能任意加入。

固定回合5其他输入，仅改变本组价格，当前模型算出：2200美元对应9.9278千单位，2508.2对应7.8075，2759对应6.5393。这说明新版确实承认高价丢份额。中性候选8.5940的生成可分解为：回合5同输入2508.2的7.8075，乘市场增长1.05成为8.1979，再叠加当前营销、研发变化成为8.5940，额外约4.83%。这不是把2759美元的实际6.45直接忽略后继续预测9.73。

进一步把本组回合5实际/拟合的差异作为固定吸引力校准（校准系数0.985576），中性需求仅从8.5940变为8.4784，稳健从7.5108变为7.4088。该校准只是诊断；本组同期残差很小，不能靠校准该点解决跨期结构问题。

## 4. “稳健”漏掉了本次最相关的风险

保存的九种情景中，价格及营销系数±20%只作用于菲律宾。联合不利情景有市场总量、对手吸引力、效率、材料和账期变化，却没有加强泰国、印尼的价格弹性，也没有检验旧市场营销、研发增益失效。故现有“稳健”不等于对印尼高价风险稳健。

固定原候选全部决策，将泰国、印尼两产品的价格敏感系数同时提高，得到以下压力回放；这是人为压力假设，不是统计区间。利润是全公司正式6税后条件利润，变化并非只由印尼梁贡献。

## 5. 优化目标和生产结构也会保留高价

当前目标是利润及现金约束，没有最低市场份额目标。即使份额只有约6%，只要模型内毛利足够，优化器仍可选择高价。用户若要求一定份额，应明确为经营约束；不能靠改需求模型悄悄实现。

中性候选梁产能54.42千单位，首班容量18.14，预测生产18.1366，几乎贴首班上限。次班工资倍数1.65、三班2.56，使降价增量可能进入更贵班次。固定其他决策降至2200美元，模型需求10.9180、梁生产20.4606，公司利润2347.56；2508.2时公司利润2679.57。1800美元时，固定分配又会触及生产上限。因此该剖面支持的是当前模型内高价的成本逻辑，不能当作低价方案的公平全参数比较。

两候选份额均低于十队平均10%，这是当前推荐接受的结果；它是否“足够”取决于利润、份额等经营要求。仅凭回合5一个高价观测，无法证明约2508美元一定卖不到7.5—8.6千单位，也无法证明能卖到。

## 6. 修复优先顺序

1. 先补齐旧市场价格、研发和营销失效的压力覆盖，撤回将现有“稳健”理解为高价风险已通过验收的表述。
2. 需求训练和应用统一研发变量定义；公司总费用代理继续作为研究对照，不解释为细分营销分配或产品研发的因果收益。缺少99队细分最终输入时，明确无法识别。
3. 比较现有对数线性价格与高价分段候选，按训练折筛选、留出市场及跨回合检验，报告高价样本覆盖和误差；不得为得到较低售价任意调系数或截上限。
4. 最后再联合求解全部可识别决策，并一致重算预估与完整字段；对确实未识别的字段保留未求解标记。若另有最低份额要求，显式加入约束。

本次未改模型和既有推荐。新品菲律宾、真实细分费用、期初财务及跨回合因果精度未在本次解决，无法交付经过验证的新最优价。
