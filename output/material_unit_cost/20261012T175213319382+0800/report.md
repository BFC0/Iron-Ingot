# 原材料单位费用模型

**独立经验模型，不替换历史财务模型。** 参数范围与回合来源须在调用时核对。

选型：proportional；最终参数=0.0013798365756。

公式：`unit_cost = published_price * (1 + parameter)`；`material_cost_kusd = production_kunits * unit_cost_usd`。基础单价为当期前景美元/单位，产量为千单位，总费为千美元。

| 基础价 | 预测单位费用（美元/单位） | 增加额 |
| ---: | ---: | ---: |
| 900 | 901.241853 | 1.241853 |
| 1053 | 1054.452968 | 1.452968 |

| 候选 | 练习两轮整市场留出MAE（千美元） | 舍入兼容条数/200 |
| --- | ---: | ---: |
| published | 19.477500 | 41 |
| additive | 2.459460 | 176 |
| proportional | 1.883333 | 200 |

先用练习1/2共200条训练选型，再回溯核验正式1的100条：MAE=1.792912千美元，最大绝对误差=5.049911千美元，舍入兼容98/100。这次模型在结果已知后建立，不是冻结事前预测成绩。

练习嵌套整市场留出MAE=1.883333千美元；外层留出市场不会参与内层模型选择。最终300条重拟合后样本内舍入兼容300/300。

拟合对总费用残差做最小二乘，不对低产量的反算单价等权拟合；若存在共同显示兼容区间，将参数限制在区间中。相同比例只有一个参数，可解释不同基础价下的不同单位差额；材料差额的内部原因仍未知。

全部300条比例参数显示兼容区间：[0.0013750635219562607, 0.0013979402751963061]。区间只反映产量±0.005千单位、总费±0.5千美元的显示兼容性，不是统计置信区间。

调用：`python code/material_unit_cost_model.py predict --model <本目录/model.json> --price 1053 --production 16.45`。训练：`python code/material_unit_cost_model.py train`，每次独立时间戳归档。

限制：前景基准仅独立采集市场5，跨市场共享为假设；只建模原材料购买，不含工资、运输、库存或其他费用；跨回合稳定性只在已观察范围检验，正式2无实际标签；舍入区间不是置信区间，真实显示舍入模式未核实；使用给定产量，产量预测误差未包括在条件误差内。跨期共享是经验假设，不是由同期市场共享要求自动推导。未来原料价格或费用规则变化时，使用新回合实际重新校准。
