# 按帮助正文检查模型自身的机制

本次更正审查标准：判断公式和代码是否表达规则规定的作用，不以“历史适用范围”“样本不足”代替结构检查。历史拟合误差小、曲线形状正确或限定范围会计平衡，都不能弥补机制遗漏。以下结论优先于前次报告的宽泛“部分符合”表述。

## 研发：已有当期和单期滞后代理，未完成机制确认及跨期利润链

帮助规定：研发改进产品，对本回合和下一回合需求都有作用；某些部分仅在下一回合产生效益；边际影响递减，不同市场重视程度不同。

现有代码不是完全忽略下一回合。`cross_market_validation.feature_matrix`及`stepwise_model.demand_features`使用`f_R(R_t+0.5R_(t-1))`；旧下期需求情景也明确把`previous_rd`设为本期`rd`。若本期单次投入1000、之后两期投入0，研发特征按有效输入1000→500→0变化。因此确实有当期和下一期的一阶滞后近似，不能把这部分误报成完全没有。

但这不是帮助所确认的完整作用机制：

- 当期投入与延期生效投入被放进同一个饱和函数，权重固定0.5，等价于一套特定且未验证的时间结构。帮助没有给出0.5，也没有确认“先相加再过同一个曲线”。这不是已证明错误的精确公式，而是不能据帮助认定正确的结构假设。
- 既有用户更正还指出曲线受上期投入条件影响。当前通用函数只有一条冻结曲线再平移输入，未建按历史条件变化的响应族，可能重复计入历史影响。
- 如果拟合版本取`rho=0`，又没有另一个延期路径，就直接遗漏帮助规定的下一回合作用。这类候选不能作为完整机制模型。
- 下期需求情景假定下期继续相同投入，不能独立评估“本期投入，下一期不再投入”的全部经营收益。更关键的是，生产财务输出不更新研发延期状态，没有逐期经营链把它接到第6回合利润。

结构验收应至少能分别设置本期、下期决策，并在其余条件固定时跟踪：本期研发→本期需求；本期研发→下期需求；各期需求→交付→各期利润。延期权重、曲线历史条件及市场响应需要证据校准。帮助只明确本期与下期，不能擅自推出研发永远累积或第2个后续回合一定仍有作用。

## 运营：持续累计状态缺失，是模型结构缺口

帮助规定：运营提高员工单位产量，立即生效并有累计效果，回报递减。

现有`operations_rho.factors`计算`f_O(O_t+rho*O_(t-1))`，再乘固定技术尺度。输入没有更早历史状态；即使调用行里带入`operations_stock`，函数也不读取它。过去投入只被记住一个回合，此后无条件消失。训练一个固定技术尺度也不能让不同队伍、不同投入路径形成各自可更新的累计状态。

本次用现有函数做脉冲检查：运营投入1000→0→0，固定rho=0.5时有效输入1000→500→0；第三期乘数恢复零投入值。再给两个当前投入、上期投入相同、早期累计状态不同的样本，函数结果完全相同。这个结果证明代码丢掉历史状态；rho具体选0.5还是1，都不能修复只保留一阶滞后的结构。

因此应把EFF判为**累计机制未实现**，OPS曲线只能判为**当期响应形状相容**，不能把两者合起来称为符合累计规则。若存在技术遗忘、折损或其他衰减，也必须有明确状态递推及依据，不能让收益因代码没有输入而自动归零。

需要的结构是：`历史运营状态 S_t = G(S_(t-1), O_t)`；`本期效率 eta_t = H(S_(t-1), O_t, 当期技术条件)`。G/H是待识别机制占位表达，不是新增部署模型或已知官方公式。必须保证即时作用和历史路径进入计算，并从本期输出下一期可用状态；不能直接把S设为无限累计支出，或凭空固定衰减率。

## 研发/运营在费用端有体现，在跨期收益端没有完整接通

`model_v2.finance.accounts`把当期研发和运营投入扣入本期费用，但把需求和效率作为外部输入，也不输出研发延期状态或运营累计状态。财务函数作为给定需求/效率的会计模块可以成立；问题出在组合链缺少机制连接。若直接优化本期利润，投入成本即时扣除，未来收益却没有完整计入，会系统性漏评延迟收益。

`horizon.remaining_profit`仅求和调用者传入的各期利润；它不计算未来需求、效率或状态转移。自检里出现`rd_stock`、`operations_stock`，只是把字典原样保留，不能作为累计机制已实现的证据。因此应判为**跨期收益模型未建立**，不只是“未来预测不确定”。

## 其他帮助对应的模型结构判断

| 帮助机制 | 模型自身判断 |
| --- | --- |
| 自由生产/需求驱动不同 | 当前函数统一截断到需求；用于自由生产产品时机制错误，需要分支与库存链 |
| 期初库存+产量供给、低优先级先短缺 | 顺序分配正确；期初库存未进入函数，是非零库存时的机制遗漏 |
| 大客户下回合交付 | 没有订单状态及交付经营链，是跨期机制遗漏；未知中标权重不能靠随意系数补齐 |
| 中标合同10%预付款、余款交付收取 | 没有预收合同负债及现金结转，是财务机制遗漏 |
| 最低现金触发短贷、有资金自动偿还 | 只报缺口，未自动借还和计息，是融资机制遗漏 |
| 累计亏损抵扣税前利润 | 税亏抵扣及余额公式已表达方向，不判为漏机制；具体税亏清算仍需独立核验 |
| 营销本期支出 | 费用已进入本期计算；提示没有给出营销无滞后，不强行判定只有当期效益 |
| 需求要素图轴 | 说明相对位置和权重，不支持把任何经验回归公式直接认证为官方函数 |
| 额外实收资本随股权交易变化 | 无股权变动时结转可以成立；若模拟发行回购，当前模型缺现金与权益变动分支 |

**这些缺失不能靠重新拟合现有系数消除。** 应先修改需要的状态与计算依赖，再用历史路径、曲线条件和平台样本验证；未知系数继续保留未知。
