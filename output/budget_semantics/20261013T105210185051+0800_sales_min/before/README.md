## 当前模型问题汇总（2026-10-12）

当前简化范围：生产策略与库存机制、自动短贷机制暂不考虑；不涉及股权变动操作。这三项不再列为当前问题或修复任务，本范围说明优先于历史审查记录。

**在上述简化范围内，研发、运营及跨回合经营收益链仍未完整接通，六回合联合优化尚未完成。** 已拟合的系数、通过的曲线形状检验和会计恒等式不能代替缺失的状态转移；以下结构问题需要改计算链，不能仅重新拟合参数。

| 问题 | 当前实现与错误/缺口 | 影响 |
| --- | --- | --- |
| 运营累计机制缺失 | `O_t+rho*O_(t-1)`只记本期和上期支出，不读取或更新更早累计状态；单次投入在第二个后续回合回到零投入乘数 | 不能按投入历史预测持续效率收益，影响用工、工资和后续利润 |
| 研发跨期机制未完整确认 | 已有`R_t+0.5R_(t-1)`及下期需求情景，不能说完全没有下期作用；但0.5、投入合并后过同一曲线、历史条件映射未验证，`rho=0`且无其他延期路径时遗漏下期作用 | 当期/延期收益无法按已确认机制分别评估，可能重复计入历史曲线影响 |
| 跨回合收益链缺失 | 研发/运营本期费用已扣除，财务输出未接入延期研发与累计运营的状态更新；六回合函数只求和外部给定利润 | 未来投入收益没有完整进入决策比较，单期最优不能当累计收益最优 |
| 大客户订单跨期机制缺失 | 没有中标订单状态、下一回合交付及产能占用链；提示还规定同等吸引力平分、客户可拒绝全部投标 | 无法完整比较投标及后续履约收益，不能假设报价就中标 |
| 预付款机制缺失 | 未处理合同金额10%预收、余款交付收取，以及预收合同负债和现金结转 | 有中标订单时本期现金、下期收款及资产负债计算不完整 |
| 多产品与当期条件未接入 | 旧需求、效率、材料、产能模型主要针对复合梁；正式3新增连接件且工资、管理费、投资单价等已变；t2v0-um仅支持回合2 | 不能复用整套旧参数预测正式3；需按产品、国家、回合和历史条件绑定 |

**仍未验证的公式与输入：**

- 研发/运营曲线依赖上期实际投入，通用训练仍使用冻结曲线与固定滞后代理；历史条件下的曲线族及逐回合选择尚未全面接入。
- 销售页四项需求乘数暂按平台给定值记录，尚无证据确认它们随当前个人输入变化；不据此分别拟合函数，也不假定跨回合不变。其进入需求模型的方式、国别营销代理、行业总量及未知对手策略仍未识别。
- softmax、投入对数尺度、风险函数、材料差额/比例等是经验结构，帮助未公布这些精确公式。平均本金/现金计息时点、税亏清算、厂房和周转规则仍需验证。
- 正式3前景文字年利率5%与参数表基准4%有来源冲突，待核；当前只保存部分当期参数摘录。条件回算、已知实际总量或期末状态的误差不能当事前预测成绩。

**已体现、不能误报为遗漏的部分：** 研发已有当期和单期滞后代理；运营用于人均效率而非直接乘需求；零库存零订单时按国家优先级交付；税亏抵扣方向及本期研发、运营、营销费用已进入计算。预算未满足需求是玩家预估与交付的差额，不能作为实际需求训练标签；这属于数据口径要求。

修复顺序：先明确历史曲线条件及研发/运营状态转移，再补订单/预付款财务链及多产品当期输入，最后接通逐回合需求→效率→生产→财务→下一期状态，并重训、独立验证和比较六回合决策。帮助未给出的系数继续保留未知，不凭空设累计率、延期权重或贴现率。

## 正式回合流程与技术步骤

正式回合按以下生命周期执行：**t回合期初状态与情境 → 模型候选方案 → 个人草稿与预算试算 → 组员协商 → 保存并核对小组决策 → 截止结算与实际结果公布 → 复盘及状态结转 → t+1回合**。

| 阶段 | 工作与生效边界 |
| --- | --- |
| 1. 确认期初输入 | 核对课程、市场、团队、正式回合及截止时间。读取期初状态、当期情境与截至t−1回合的已公布结果；公司状态与市场情境分别记录，注明来源、有效期及缺口。正式1从初始0开始，不继承练习2状态。 |
| 2. 生成模型方案 | 根据期初输入，预测候选决策下的需求、交付、利润、现金及后续影响。在约束、竞争假设与不利情景下，比较截至正式6的剩余累计收益；建议是模型条件下的较优方案，不保证真实或全局最优。保存模型版本、输入、假设与事前预测。 |
| 3. 填写个人草稿 | 用户将方案填写到自己的个人决策区域，检查平台预算并调整。个人保存不会自动修改小组决策；其他成员在各自个人区域的修改，不改变本人的个人输入与预算。平台预算依赖输入和玩家预测，不是实际销售或已实现财务结果。 |
| 4. 协商小组方案 | 用户在平台外与组员协商，确定最终小组方案。若最终方案不同于模型建议，应重新核算需求、生产、物流、融资与现金匹配，并记录最终方案对应的预测。 |
| 5. 保存并核对小组决策 | 用户或组员将协商结果保存到小组决策区域，核对最终数值。至此本组决策工作完成，但截止前小组区域仍可修改；实际生效的是截止时保留在小组区域中的内容。个人草稿不自动生效。 |
| 6. 截止结算与发布 | 截止时，系统依据本组及同编号市场内竞争小组的最终决策、模拟规则和市场条件计算并公布实际结果，形成t回合期末状态。个人草稿彼此独立，不代表正式经营结果不受竞争影响。 |
| 7. 复盘并开启下一回合 | 按[每回合结束后工作清单](每回合结束后工作清单.md)依次归档、核验、评分原冻结预测、分析偏差、更新模型和问题清单、结转状态、核验下一回合前景与新曲线，再交付复盘及交接。正式6改为终局核验与封存。 |

**继承口径：**继承的是状态与持续影响，不是所有报表数字原样延续。现金、债务、库存、资产等按规则衔接；当期销售收入、成本和利润属于发生额，下一回合重新计算，累计指标另行累积。研发、营销、运营及投资的延续与生效时点逐项核验，不一律视为永久或立即生效。情境中的持续条件和未来信号须保留原来源与有效期，并以新回合资料核验；不能把上一回合参数直接当成下一回合已知事实。未知状态不补零。

本节规范用户及小组的完整流程；本次写入文档不恢复此前暂停的助手推荐值填写，也不授权助手修改或提交小组决策。助手操作仍遵守上文“已有要求与操作边界”。规则依据：[决策指南逐页文本](sources/决策指南_逐页文本.txt)。

### 补证与个人区预算试验边界

- 可增量读取网页可见规则、参数、曲线和实际结果。用户已选择包含可恢复个人预算试验；仍禁止推荐值填写、小组提交、导入小组决策、覆盖其他成员，以及联系其他小组或教师。
- 每次操作先确认当前开放回合、身份、市场、截止时间与最新基准；过期正式1不得继续操作。首次使用控件按[保存标准操作](原生键盘标准操作.md)验收。
- 固定无关需求、效率和利率预测，每次只变一个字段。试验点包括班次/解聘边界两侧、机器投资0/1/10/20（限合法值）、现金触发点两侧及内部验证点；保存完整损益、现金流、资产负债和相关生产物流表。
- 每项执行输入确认、个人列确认、重入回读、恢复、再回读；恢复试验前最新值，不用旧档覆盖成员后续修改。每个机制至少保留一个未参与校准的有效试验作验证；未保存或未恢复样本不得拟合。
- 回合变化、基准被他人改动或恢复失败时停止扰动并报告当前状态。预算只验证预算机制，不能证明真实需求、价格弹性或投入因果效果。

### 全面压力测试

覆盖A/B及新版领先模型、初始0/练习1/练习2对手策略、竞争降价与增加投入、两国分别及同时需求下降；同时覆盖正则候选、研发/运营延续、分段价格、极端样本、曲线外推、效率、班次/解聘、产能不足、材料/运输、两种风险函数、利率、回款延迟、还贷、短贷及跨回合状态。

- 初始档位：需求±10%、±20%、-30%；效率±0.005和±0.01；成本±5%和±10%；利率增加0.5和1个百分点；应收天数30/45/60。均标明历史证据或假定来源，不能伪装为官方参数。
- 确定性测试包括单因素、关键两因素组合与组合不利情景。每个最终候选另做固定种子的2000组分层范围抽样，覆盖多因素同时变化；抽样范围及生成方法保存，避免无意重复施加同一需求冲击。
- 检查利润、现金、短贷、交付、库存、权益及期末状态。未完整计算的分支标记范围外，不按完整利润排名。
- 抽样失败占比与分位数仅描述测试集合，不称为真实概率；情景区间不称为置信区间；测试最小值不称为全部可能情况的最坏值；现金达标不代表保证盈利。
