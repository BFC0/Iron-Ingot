# t4v1a 非重训优化与对照

不要输出真名，姓名统一用首字母替代。

独立保留29类模型及冻结候选；训练回合3，应用情景回合4。未重训、未选参、未采集或修改平台，t4v1保留。

## 已应用与对照

- 正式4参数：基准利率5%、短贷溢价3个百分点、工资33千美元/人；机器58／1美元/单位；材料1053／14.20美元/单位。
- 行业情景：复合梁−15%／−17.5%／−20%，连接件+5%；两国分别缩放真实需求总量。
- 主份额保持SHARE；COUNTRY与连接件线性价格候选分列；ABS仍仅诊断，没有默认平均。
- 三条回合4曲线冻结保存，上期投入1000／400／600、情境与范围核验；有效坐标求值开放，但自动支出映射跳过。
- 运营历史候选仅用冻结参数复算，并在历史效率保持、固定产量和当期工资下比较人员、工资、解聘费及材料成本。
- 杠杆幂函数禁止应用；指数函数仅限范围内显式状态情景，5%与4%利率差及税前现金敏感性单列。

## 缺数据跳过

- RD/OPS/EFF_FORWARD：曲线来源及上期投入已核实；当期支出→有效横轴映射、完整存量未证实。
- SHARE/COUNTRY_REAL_INPUTS：99队产品/国家分配缺失；本组曲线不可推广其他队。
- CAPACITY：投资生效时点冲突；仅更新机器单价，不排名投资收益。
- FINANCE：期初/期末/平均风险状态与计息时点未识别；税亏、完整现金链缺失。
- CONNECTOR_V2：机会不是确认订单；中标、交付及实际预收余款状态缺失。
- MATERIAL_TRANSFER：缺新基价实际标签；只作固定参数敏感性。
- HORIZON：正式4→5→6前景及完整结转状态缺失，不计算剩余利润排名。
- NESTED_DEMAND_COEFFICIENT_REPLAY：旧嵌套留出只保存配置和预测，未保存每折系数；只核验保存预测的指标，不重训恢复系数。
