## 6. 目标、模型要求与尚未实施的设计

主目标应与平台累计收益评分一致：`累计收益_期末 = 起始累计收益 + Σ(正式回合t税后利润)`，优化 `max E[累计收益_正式6]`，并报告不利情景结果。期望优化需要有来源的情景概率；如果概率无法估计，应报告区间与各情景收益，并明确采用的稳健决策准则。不能擅自换成营收、现金余额、ROE或仅一回合利润。

未来正式回合市场和对手决策未知，因此只能做有假设的滚动优化，不能承诺数学意义的全局最优。每回合结果出来后更新数据和参数，重新计算剩余回合。以下公式仅为后续建模候选，**尚未拟合、运行或据此填值**。

| 预测对象 | 候选模型与公式 | 校准与限制 |
| --- | --- | --- |
| 总市场需求 | `M[m,t] = M[m,t−1] × (1 + g[m,t])` | g来自本回合前景和历史总需求；构造有证据的低/中/高情景，不能无依据指定百分比 |
| 公司需求 | `d[i,m,t] = M[m,t] × exp(U[i,m,t]) / Σj exp(U[j,m,t])` | U可含相对价格、营销、设计、质量和品牌状态；系数需拟合和验证。检查总需求口径及竞争者缺货再分配机制 |
| 价格效应备选 | `log d = a − e × log(p / p_ref) + b × log(1 + marketing) + …` | e不能从两次混杂变动直接认定；避免对历史零值取log，需合理处理接近零需求 |
| 持续营销或研发 | `S[t] = ρ × S[t−1] + f(支出[t])` | ρ和收益递减函数f待规则、曲线与历史校准，不能假定当期支出等于当期效果 |
| 生产效率 | `e[t] = h(历史效率、运营改进、前景)`，`人数 ≈ 产量 / e[t]` | 已填0.15未验证；练习实际显示约0.17，需要核验精度与持续效应 |
| 利息 | `利息 = 计息余额 × 实际利率` | 风险溢价、计息时点待核；预测利率字段不是可控制的金融价格 |

生产和投资模型需包含机器新增、15%能力衰减、适用厂房约束、投资生效时间、分班工资和解聘费用。候选分班成本公式为：令q为产量、K为三班总产能，`q1=min(q,K/3)`，`q2=min(max(q−K/3,0),K/3)`，`q3=max(q−2K/3,0)`；`工资≈(q1 + 1.65q2 + 2.56q3) / e × 基础工资`。该分解需对照平台回算，不能在未验证时视为官方完整公式。第一班三分之一产能通常成本较低，增产可能进入高工资班次。

数量守恒要求 `期末库存 = 期初库存 + 生产 − 国内销量 − 出口销量 − 大客户交付`，各销量非负且受真实需求和可供应数量约束。总现金流应涵盖税、利息、营运资本、投资和贷款，并满足最低现金2,000千美元，避免自动短贷；机器投资按页面整数范围处理。利润应依据收入、原材料、人员、运输、库存费用、营销、研发、运营改进、管理、解聘、折旧、财务与税费计算，税亏抵扣等未知机制需核对。不得把机器购买额全部直接当作当期利润费用，亦不得漏记现金流出。

本回合无大客户订单，不凭练习2截图加入招标。未来出现订单时再纳入跨回合交付、优先供应与预收款约束。贷款偿还、投资和生产应联合搜索，不能各自局部最优后简单拼接。

## 7. 工作流程与验收要求

1. 恢复时先核对登录、市场5、正式回合、截止时间和PYT个人区域；读取最新状态并保留增量版本，不能使用旧快照覆盖成员新改动。

3. 建立结构化输入数据，区分实际结果、平台预算、遗留预测和模型预测；校验总量、队列顺序、重复字段与财务平衡。
4. 按规则建立可计算模型，先回算初始、练习与现有正式预算；记录误差和无法解释项。
5. 拟合预测并做留出/回测和参数敏感性分析；数据不足时明确参数范围和情景来源，限制自由度。
6. 联合搜索定价、营销、生产、投资、研发、运营、物流与融资；每个候选记录约束、现金、当期和剩余期收益。
7. 形成推荐决策表：字段、当前值、建议值、预测模型或公式、源文件、理由、风险、替代方案。列出相对当前方案的收益变化与不利情景。
8. 用户恢复填写流程后，将确认的结果填入个人区域，逐字段回读并归档前后截图与平台预算。对照本地模型，重大不一致先排查。
9. 小组正式决策另行协调与核对；个人填入不等于小组提交，不擅自覆盖其他成员区域。最新暂停期间两者都不做。
10. 结果出炉后，以实际需求、销售、库存、利润及竞争者行为更新模型，继续优化剩余正式回合。

验收必须同时满足：来源可追溯；预测模型与参数可解释；所有计算可在Python复现；单位正确；约束可行；平台与模型偏差可解释；当前与建议决策可比较；回读值与建议一致；无误改小组或成员区域。不能仅用平台预算提高就声称达到最终累计收益最优。
