## 1. 行业总需求与增长情景（通用或历史公式）

回溯外推：`T̂_t = T_(t−1)^2 / T_(t−2)`，沿用上一回合的增长比例。

正式1冻结规模情景：`T̂_formal1 = T0`（不增长）或`T0 × (T_practice1/T0)`（沿用本市场练习1增长）。后者数值等于本市场练习1总需求，但不继承练习财务状态。

给定增长情景：`T̂_(t+1) = T_t × (1+g_T)`；行业增长输出：`g_T = T̂_(t+1)/T_t−1`。

T按同编号市场、阶段、回合、国家汇总实际需求，不能汇总销量或玩家预测；g_T为假定或历史外推的行业增长率。历史分母为零或缺失时不输出上述比例。此模型未独立识别行业营销、宏观趋势与行业价格的影响。

## 2. 竞争需求份额模型（历史A/B）

`u_i = −e_c ln(P_i/P0_i) + b_G ln(1+G_i/1000) + b_H ln(1+H_i/1000) + b_R ln(f_R(R_i+ρ_R R_(i,t−1)))`

`ŝ_i = exp(u_i)/sum_(j∈J) exp(u_j)`；`D̂_i = T̂ × ŝ_i`。

| 变量/参数 | 含义 |
| --- | --- |
| u_i | 无量纲相对吸引力得分，不是利润或平台公布指标 |
| ŝ_i | 预测需求份额，0至1；同一J内合计为1 |
| P_i/P0_i | 本组价格相对已知初始价格；跨市场脚本使用本组初始值，原分步脚本使用国别参考价1800/2000 |
| e_c | 国别相对价格敏感系数；该历史版本要求非负，不直接等于绝对需求弹性 |
| b_G、b_H、b_R | 一般营销、设计师营销、研发曲线的作用系数；要求非负，表示模型内条件关联 |
| ρ_R | 上期研发延续权重，该历史版本假定0.5；不是已识别的完整研发存量 |
| f_R | 第6项研发乘数曲线，须为正才能取对数 |
| 1000 | 投入变换的尺度常数，单位千美元；不是平台收益阈值 |

营销只有合计代理，没有假定分配到各国家。A只训练市场5；B使用符合条件的多个市场，每个编号市场总训练权重相同。两者均按J分别归一化。正式对手策略未知，冻结预测分别假定对手沿用初始0或练习1策略。

训练关系：`ln(D_i)−组内均值[ln(D)] = (x_i−组内均值[x])·β`。x是上述5列特征（两国价格各一列及三项投入），β是5个系数；训练使用非负系数与岭惩罚λ，λ仅在训练部分选择。零需求排除对数拟合但保留评价。行业规模T不由该去均值拟合估计。

该历史版本A/B冻结参数：[参数档案](output/cross_market/parameters_latest.json)。旧分步模型的冻结参数仍保留，不能把不同训练回合或版本的系数拼接。

## 3. 只使用自身策略的需求模型（A/B对照）

`D̂_i = exp(α_c + u_i)`。

u_i使用第2项相同特征形式，但系数另行拟合；α_c为国别截距，决定绝对需求基准，可为任意实数。该模型不使用对手策略，不保证同市场需求合计等于T̂。用于相同切分下比较竞争信息的预测价值，不是该历史版本冻结正式1情景的主预测器。

## 4. 等份额基线与实际总量诊断（对照）

等份额：`ŝ_i = 1/n_J`；`D̂_i = T̂/n_J`，n_J为本竞争集合的团队数。

实际总量诊断：`D̂_i,oracle = T_actual × ŝ_i`，T_actual是验证期已公布的实际总需求，ŝ来自竞争模型。后者只诊断份额，不是事前可实现预测；不能用其误差替代正式预测误差。

## 5. 原绝对对数需求模型（历史版本）

`D̂_i = exp[α_c − e_c ln(P_i/P0_c) + b_G ln(1+G_i/1000) + b_H ln(1+H_i/1000) + b_R ln(1+(R_i+ρ_R R_(i,t−1))/1000)]`。

变量含义与第2、3项相同；P0_c为泰国1800、印尼2000美元/单位。区别是研发直接使用log1p投入代理，不通过f_R；系数和ρ_R来自该历史模型自身档案。该历史版本竞争模型已将行业规模和份额分开，旧版只保留作历史核验，不与新版参数混用。

## 6. 研发乘数曲线（通用或历史公式）

`x_R = R_t + ρ_R R_(t−1)`；`f_R(x_R) = a_R + b_curve,R (x_R+c_R)^d_R`。

| 参数 | 含义 | 历史拟合值 |
| --- | --- | ---: |
| x_R | 假定有效研发投入，千美元 | 由决策与上期投入计算 |
| a_R | 曲线垂直偏移，无量纲 | −0.029189 |
| b_curve,R | 幂曲线幅度系数，与份额模型b_R不同 | 0.278970 |
| c_R | 横轴平移，千美元 | 0.750996 |
| d_R | 幂指数，无量纲 | 0.204058 |

参数来自可见曲线拟合；代码将曲线输入下限截为0。拟合曲线不等于识别实际需求公式或历史投入累积规则。

## 7. 运营曲线与生产效率（通用或历史公式）

`x_O = O_t + ρ_O O_(t−1)`；`f_O(x_O) = a_O + b_curve,O x_O/(c_O+x_O)`；`η̂ = θ × f_O(x_O)`。

| 参数 | 含义 | 该历史版本值/来源 |
| --- | --- | --- |
| x_O | 假定有效运营投入，千美元 | 该历史版本与上期投入 |
| ρ_O | 运营延续权重 | 0.5；另保留0、1敏感性 |
| a_O | 零有效投入下的曲线乘数 | 0.45 |
| b_curve,O | 曲线可增加的乘数幅度 | 0.75 |
| c_O | 饱和曲线尺度，千美元 | 400.105820 |
| θ | 技术基底尺度，千单位/人 | 练习1实际产量/人数除以曲线乘数后的均值 |
| η̂ | 预测人均产出，千单位/人 | θ与运营曲线的乘积 |

θ、历史存量及未来技术趋势未完全分离，不能自动假定以后回合θ恒定。效率实际标签使用q/N，不直接把页面两位小数当精确值。

## 8. 产能、产量与交付（历史条件模型）

`C_t = 0.85 C_(t−1) + I_t`；`K_machine = p_I I_t`，该历史版本机器单位投资成本p_I=100千美元/千单位。

`q̂ = min(C_t a/100, sum_c D̂_c)`；需求驱动候选分配：`a_candidate = 100 min(sum_c D̂_c/C_t,1)`。

按交货优先级π，依次计算`Ŝ_c = min(D̂_c,Q_remaining)`，随后将剩余供给Q_remaining减去Ŝ_c；初始Q_remaining=q̂。候选优先级按P_c−k_c由高到低比较，k_c为单位运输费。

a为产能分配百分数；I_t为机器投资新增产能；K_machine为机器投资金额；π为两国交付顺序。该历史版本公式适用于零期初库存、零大客户订单，不包含非零库存释放或订单预留。分配候选只在已检查边际贡献为正的情景使用，不是普遍最优公式。

## 9. 用工、班次工资与解聘（通用或历史公式）

`q1=min(q̂,C/3)`；`q2=min(max(q̂−C/3,0),C/3)`；`q3=max(q̂−2C/3,0)`。

`N̂ = q̂/η̂`；`W = (q1+κ2 q2+κ3 q3)w/η̂`；`F = max((1−δ)N_(t−1)−N̂,0)wσ`。

q1、q2、q3为三个班次产量（千单位）；W为生产工资成本；F为解聘成本（均千美元）。该历史版本w=28千美元/人，κ2=1.65、κ3=2.56为第二、第三班次工资倍数；δ=0.10为自然减员比例，σ=0.35为解聘补偿工资比例。人数为连续量近似，未另行加入整数排班优化。

## 10. 营业收入、成本与经营利润（通用或历史公式）

| 输出与公式 | 变量含义 |
| --- | --- |
| V=sum_c(P_c Ŝ_c) | V营业收入；Ŝ是可交付销量，不是需求 |
| B=q̂(v+Δv) | B原材料总额；v为当期公布单价，Δv为练习1拟合单位差额1.176471美元/单位 |
| Z=sum_c(k_c Ŝ_c) | Z运输费；该历史版本k_泰国=30、k_印尼=120美元/单位 |
| A_marketing=G+H+50 | 营销费用；固定50千美元项来自该历史版本场景，不是新增拟合系数 |
| A_overhead=4000+F+R+O | 其他经营费用；4000为该历史版本固定管理成本，F解聘费，R研发，O运营投入 |
| EBITDA=V−B−W−Z−A_marketing−A_overhead | 折旧、利息、所得税前经营利润 |
| Dep_machine=0.15(Book_machine,0+K_machine) | 机器折旧；Book_machine,0为期初机器账面价值 |
| Dep_building=0.07 Book_building,0 | 厂房折旧；Book_building,0为期初厂房账面价值 |
| EBIT=EBITDA−Dep_machine−Dep_building | 息税前利润 |

厂房当期投资K_building=800千美元。这些成本、折旧和固定金额只在已归档场景范围核验；未来回合须更新前景参数，不能照搬所有常数。

## 11. 贷款风险溢价与利率（历史及备选）

该历史版本候选（未部署）为权益/资产指数模型：`r_L = r_base + a_r exp(−b_r E/A)`。

同时拟合但未作为该历史版本候选（未部署）的债务/权益幂模型：`r_L = r_base + a_r ((L+L_short)/E)^b_r`。

| 变量 | 含义 |
| --- | --- |
| r_L、r_base | 长贷年利率、当期基准年利率（小数）；该历史版本正式1r_base=0.03 |
| E、A | 期末权益、期末资产，千美元；E/A为权益比率 |
| L、L_short | 期末长期、短期贷款余额，千美元；(L+L_short)/E为杠杆比率 |
| a_r、b_r | 各风险候选单独拟合的幅度和形状参数；a_r与利率同尺度，b_r无量纲 |

部署候选按练习1训练误差选择，不按练习2结果选型。事前预测必须用预测的E、A联立计算利率，不能输入未来实际状态。该历史版本完整财务链只覆盖零短贷范围，权益不为正时风险模型不输出完整预测。

## 12. 利息、税、利润与现金联立（通用或历史公式）

| 输出与公式 | 变量含义 |
| --- | --- |
| L=L0+ΔL | L0期初长贷；ΔL本期贷款增减金额 |
| J_L=(L0+L)r_L/2 | J_L长期贷款利息 |
| AR=V×30/365；AP=B×30/365 | AR应收款、AP应付款；30为该历史版本周转天数，365为年天数 |
| Cash_pre=Cash0+EBITDA−J_L+(AR0−AR)+(AP−AP0)−K_machine−K_building+ΔL | Cash_pre为现金利息与税前的现金；下标0为期初余额 |
| J_C=max((Cash0+Cash)/2,0)r_C | J_C现金利息收入；Cash期末现金，该历史版本r_C=0.01 |
| PBT=EBIT+J_C−J_L | PBT税前利润 |
| Tax=max(PBT−Loss0,0)τ | Tax所得税；Loss0期初可用税亏，该历史版本τ=0.29 |
| Profit=PBT−Tax | Profit税后利润 |
| Cash=Cash_pre+J_C−Tax | 期末现金，与J_C、Tax迭代联立 |
| E=E0+Profit | E0期初权益；该历史版本无分红分支 |
| Book_machine=Book_machine,0+K_machine−Dep_machine | 期末机器账面价值 |
| Book_building=Book_building,0+K_building−Dep_building | 期末厂房账面价值 |
| A=Book_machine+Book_building+AR+Cash | 该历史版本范围期末资产，库存为零 |
| A=L+AP+E | 资产负债自检式；该历史版本无短贷余额 |
| Loss_end=max(Loss0−max(PBT,0),0)+max(−PBT,0) | 模型结转的期末税亏；亏后转盈处理尚未独立验证 |
| L_short,needed=max(Cash_min−Cash,0) | 最低现金缺口；该历史版本Cash_min=2000千美元，只标记所需短贷 |

Cash、利率、利润、权益和资产相互影响，属于联立链而非多个独立回归。若需要短贷，尚无完整短贷利息模型，此时输出标为超出已识别范围，不把上述Profit称为融资后的最终利润。

## 13. 下回合公司需求增长（条件情景传播）

`g_D = D̂_(t+1)/D̂_t−1`；该历史版本公司总需求使用两国D̂之和计算。g_D为公司需求增长率；D̂_(t+1)由下一回合行业规模、竞争策略、价格投入及研发传递假设重新计算，不是独立拟合增长回归。

分母为零时比例未定义；未来前景或对手策略未知时只输出明确的情景，不将情景端点称为置信区间。

## 14. 决策比较与尚无模型的项目

用户2026-10-11明确整个流程只有正式6回合。长期投入收益、投资和贷款节息须按第t至第6回合累计利润评价，不能使用无限期限或正式7以后的收益。期末资产及投入存量不自行加入利润，债务不默认强制清偿；终局处理须有规则依据。待细化参数及具体调整要求见[独立清单](参数细化与六回合期限要求.md)。此段为新要求，尚未表示旧模型已完成期限调整。

价格、投入、产能分配、交付顺序、投资及贷款是候选决策输入。现有程序将候选代入上述链，在多个规模与对手策略情景下比较Profit；部分网格按最差情景利润排序。该程序不是预测对手策略的模型，也没有完成正式6累计利润动态优化。

大客户该历史版本无有效中标样本/交付样本，未拟合中标评分或订单概率模型。国别营销分配、全行业投入影响总需求的函数、完整投入存量、非零库存、短贷计息、正式与练习函数变化均未独立识别；不能为这些项目补写确定公式。
