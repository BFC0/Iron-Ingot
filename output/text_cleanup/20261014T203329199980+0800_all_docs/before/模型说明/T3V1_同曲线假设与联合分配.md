## 明确假设与来源

**现假设连接件的单产品曲线与复合梁相同。** 来源为正式3市场前景中的“每组产品”“产品组合”：

> 贵公司已决定扩大其产品组合，以涵盖连接件。

> 在给定的价格水平下，泰国和印尼对每组产品的初始需求量分别约为 250 000 单位和 150 000 单位。

完整原文、归档路径与SHA256在[假设档案](../output/t3v1/20261013T193815695205+0800/assumption.json)。归档为市场5、正式3、2026-10-13。上述表述是用户指定假设的来源，并非官方直接证明两产品曲线相同。

具体实现：两产品共用归一化价格、营销、研发的需求响应系数，以及同回合复合梁研发曲线。正式3连接件原始研发曲线仍独立保存，不覆盖成复合梁曲线。运营改进使用同一国家曲线，但连接件的效率基底必须独立提供。相同曲线不意味着售价、市场总量、材料/运输费用、效率基底或机器产能相同；也没有加入未证实的交叉替代、互补或捆绑效应。

价格按各产品基准价归一化，连接件27美元基准在演示中作为情景设定。营销/研发投入仍使用千美元的现有尺度；未来如需按产品市场大小重新缩放，应建立独立版本。正式2行为参数迁移至正式3亦为尚未验证的跨期假设。

## JOINT_ALLOCATION_V1

该模型以训练后的双产品需求预测为输入，联合求产量和交付。它是约束预测/优化模型，尚无“最佳比例”标签用于监督训练。

| 输入 | 含义与单位 |
| --- | --- |
| D_p,c | 产品p、国家c的需求预测，千单位 |
| C_p | 产品p独立机器产能，千单位 |
| η_p | 产品p的生产效率，千单位/人 |
| P_p,c | 售价，美元/单位，必须与需求模型输入一致 |
| M_p、L_p,c | 材料与运输费用，美元/单位 |
| W | 基础生产工资，千美元/人 |
| m_s | 三个班次工资乘数，现有规则1、1.65、2.56 |
| N | 共享生产用工上限，人；传null表示不施加该上限 |

决策为产品p的三个班次产量`q_p,s`及国别交付`sales_p,c`：

`max Σ_p,c (P_p,c-L_p,c) sales_p,c - Σ_p,s (M_p+W m_s/η_p) q_p,s`

约束：`0≤q_p,s≤C_p/3`，`0≤sales_p,c≤D_p,c`，`Σ_c sales_p,c=Σ_s q_p,s`；给定共享用工上限时，`Σ_p,s q_p,s/η_p≤N`。复用已安装SciPy线性规划，三班成本依次非递减。负贡献时允许停产。

输出各产品产量、两国交付、未满足需求、班次产量、工资及当期贡献，并区分三种比例：

- **产能分配百分比**：本产品产量/本产品机器产能，各自0–100%；两项不要求相加为100%。
- **数量占比**：本产品产量/两产品总产量；总产量为0时两项为0。
- **用工占比**：本产品人数/两产品总人数；总人数为0时两项为0。

两种产品具有独立机器产能，未假定其产能可以相互转移。数量占比也不能用于替代产能填写比例。正式3归档连接件产能为0，在该条件下模型必然给出连接件产量0。
