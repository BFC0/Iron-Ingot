# t5v0复合梁材料嵌套留出误差诊断

分析日期：2026-10-15（北京时间）。不要输出真名，姓名统一用首字母替代。

结论：复合梁材料嵌套整市场留出MAE为 **2.557838千美元（约2558美元）**。主要解释是高单价放大了产量显示精度的影响；现有证据没有显示明显过拟合或跨市场失稳。全部留出残差均与既定显示舍入假设兼容，但这不能证明误差完全来自舍入，也不能证明真实采购机制已识别。

## 1. 绝对金额显得大，经营比例很小

连接件各市场有效样本数不同，市场等权MAE与逐队MAE略有差别。复合梁每市场10条，因此两个口径相同。跨产品只比较千美元MAE会忽略单价和显示精度差异。

## 2. 高单价把产量舍入放大为数千美元

材料公式为 `费用（千美元）=产量（千单位）×单位材料成本（美元/单位）`。正式4复合梁公布单价1053，全样本拟合有效单价为1054.453411美元/单位。归档产量显示半格为0.005千单位，即5个单位，材料费显示半格为0.5千美元。

在最近四舍五入假设下，显示误差传播包络为：

`|预测费用−显示费用| ≤ 0.005×拟合单位成本+0.5`

| 项目 | 复合梁 | 连接件 |
| --- | ---: | ---: |
| 拟合单位成本，美元/单位 | 1054.453411 | 14.219726 |
| 产量半格单独传导，千美元 | 5.272267 | 0.071099 |
| 再加费用半格的总包络，千美元 | 5.772267 | 0.571099 |

复合梁最大残差5.465309千美元仍在包络内，全部100条均兼容；区间外残差为0。进一步用每条产量和费用区间反算，100条存在共同单位成本区间 **[1054.422887,1054.492060]美元/单位**，说明无需引入市场专属材料成本，也能与全部显示值同时兼容。该全样本交集只作事后诊断，没有用于外层留出拟合。

若仅作数量级直觉，假定产量舍入误差近似均匀，其单独贡献的期望绝对费用差约为`1054.453411×0.005/2=2.636134千美元`，与观测2.557838接近。这是说明性假设，并非已验证的舍入分布或误差分解。

## 4. 原始单价差额确实存在，但已被经验修正吸收

只用公布价1053美元/单位，复合梁MAE为24.676900千美元，仅7/100条舍入兼容。拟合增加约1.453411美元/单位后，留出MAE下降约89.63%，并达到100/100兼容。因此不能把原始公布价与费用之间的全部差额都解释为舍入；当前2.56千美元是经验修正之后的剩余误差。为何有效单价高约0.138026%，现有资料不能识别，不将其直接命名为采购附加费或损耗。

正式4所有复合梁样本公布价相同，加法修正与比例修正在本批数据上代数等价。外层折在两种名称之间切换来自约10^-12量级的浮点评分差异，不是材料机制频繁变化；本批数据不能判断未来价格变化时该用固定加价还是固定比例。原选择器优先比较舍入兼容条数，再比较MAE；此次两种修正均100/100兼容，且预测等价，不影响本结论。

## 5. 处理建议与未验证项

当前保留简单材料模型即可。后续报告同时列市场等权MAE、WAPE、最大残差和舍入兼容数；不为压低显示值MAE增加市场特征或复杂函数。若需要辨别小于数千美元的真实费用差，优先补更高精度产量与费用，或独立机制证据。

| 当前问题 | 状态与影响 | 下一步 |
| --- | --- | --- |
| MAE缺少规模和精度背景 | 本诊断已补充，2.56千美元不代表费用预测存在显著比例偏差 | 后续模型报告沿用并列指标 |
| 选型对浮点末位敏感 | 名称切换已解释，本批预测等价 | 后续维护时对等价候选固定优先级；本次不改模型 |

| 因缺数据无法验证的问题 | 限制 | 所需证据 |
| --- | --- | --- |
| 内部精度与舍入方式 | 区间兼容不等于已证明实际误差成因 | 高精度内部产量/费用或独立规则 |
| 公布价与有效价的差额机制 | 经验拟合不等于真实采购机制 | 采购计价规则及独立验证 |
| 跨回合稳定性、加法与比例辨别 | 同期市场留出不能代表未来回合精度 | 不同基础价下的独立后续数据 |
| 端到端材料费用预测 | 当前使用已实现产量，未包含产量预测误差 | 冻结决策到实际产量、费用的完整验证 |
