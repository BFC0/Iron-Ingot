## 回算方法和误差

金额单位千美元，数量千单位，价格美元/单位。误差定义为观测值减计算值。

| 检查 | 公式 | 历史最大绝对误差 |
| --- | --- | ---: |
| 未满足需求 | 实际需求 − 实际销量 | 0.01千单位 |
| 销售收入 | Σ国别销量 × 国别售价 | 16.5千美元 |
| 数量守恒 | 两国销量 + 大客户交付 = 生产 | 0.01千单位 |
| 毛利 | 收入 − 可变成本 | 1千美元 |
| EBITDA | 毛利 − 营销销售总成本 − 杂费总成本 | 1千美元 |
| EBIT | EBITDA − 厂房折旧 − 机器折旧 | 1千美元 |
| 税前利润 | EBIT + 利息收入 − 长贷利息 − 短贷利息 | 1千美元 |
| 税后利润 | 税前利润 − 直接税 | 1千美元 |
| 资产负债平衡 | 总资产 = 负债及权益总计 | 0 |
| 期末现金 | 期初现金 + 经营现金流 − 资本支出 + 长短贷变化 | 1千美元 |
| 累计收益 | 上回合累计收益 + 当期利润 | 1千美元 |

收入误差按页面销量的0.01千单位精度核验：容差为 `0.005×(泰国售价+印尼售价)+0.51` 千美元；其余财务求和按整数显示精度设置1—2千美元容差。数量守恒当前三轮库存均为0；不能将该简式直接用于未来有库存的回合。财务恒等式使用报表中的成本、利息和税额，只检验表内一致性，不代表这些机制已经全部独立预测。

正式预算A及有效B的EBITDA、EBIT和税前利润同样回算通过。有效B只有已归档损益/物流，未将A的资产负债及现金流表拼成B的完整预算。

## 基础生产与物流模型

源码 `production_and_delivery` 实现零期初库存、无大客户订单、需求驱动生产及两国优先交付。参数来自 `raw/round1_outlook.json`；产能/利用率/效率来自 `raw/round1_production.json`；期初人员来自 `raw/initial0_printable.json` 第1269行、第6队。

`q = min(产能×分配比例, 泰国需求+印尼需求)`。按物流优先级逐国交付，销量不超过需求或剩余供应。

将三班产能等分为三段，第一段工资权重1，第二段1.65，第三段2.56：`工资 = Σ(分段产量×工资权重)÷效率×28`。`解聘费 = max(上期人员×(1−10%)−本期产量÷效率,0)×28×35%`。

| 项目 | A：需求5/11 | B：需求1/11 | 平台对照 |
| --- | ---: | ---: | --- |
| 产量 | 3.4 | 3.4 | 相符 |
| 两国交付 | 3.4/0 | 1/2.4 | 相符 |
| 工资 | 634.667 | 634.667 | 显示635，误差0.333 |
| 解聘费 | 715.521 | 715.521 | 显示716，误差0.479 |

代码另有零产量、需求限制、三班工资、反向优先级及非法利用率的自检。A/B产量相同，均未跨入第二班；三班公式是候选模型，尚不能称为全产量范围的平台代理验证。没有新增网页扰动样本。
