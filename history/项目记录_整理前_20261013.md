## 复现与版本管理

在项目根目录使用已安装NumPy/SciPy的Python。以下是可用入口，本次文档整理未重训模型。

| 命令 | 作用与写入影响 |
| --- | --- |
| `python code/build_model_inputs.py` | 重建基础输入、历史样本及基础回算结果 |
| `python code/fit_demand.py` | 重训历史绝对需求模型，覆盖该版结果JSON |
| `python code/stepwise_model.py` | 重建分步拟合、情景、报告及相关归档索引/哈希 |

本地 Git 使用 main 分支，保存代码、说明、原始数据、核验和冻结结果；忽略Python缓存及Office临时锁文件。暂无远程仓库。

```powershell
git status --short
git diff
git add -A
git commit -m "说明本次数据或模型更新"
git log --oneline -5
```
